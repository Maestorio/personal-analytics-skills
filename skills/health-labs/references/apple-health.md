# Импорт давления и пульса из Apple Health (режим D)

Скрипт `scripts/apple_health_bp.py` (stdlib only). Вход — `export.zip` или
`export.xml` из «Здоровья» (профиль → «Экспортировать все медданные»). Файл
кладут в папку «Медицинские анализы» или называют путь в запросе. Экспорт бывает
в сотни МБ: разбор потоковый (`iterparse`), zip читается без распаковки на диск,
файл проходится дважды (замеры давления, затем пульс только вокруг них).

```
python3 scripts/apple_health_bp.py --root "$HEALTH_ROOT" plan  EXPORT [--since YYYY-MM-DD]
python3 scripts/apple_health_bp.py --root "$HEALTH_ROOT" apply EXPORT [--since YYYY-MM-DD]
```

`plan` ничего не пишет: новых дней, пропуски по причинам, диапазон дат, примеры.
Показать сводку пользователю, дождаться «да», затем `apply`.

## Что берётся
- Давление — `Correlation` типа `HKCorrelationTypeIdentifierBloodPressure` с
  вложенными `Record` Systolic и Diastolic. Одиночные записи вне корреляций не
  учитываются.
- Пульс — `HKQuantityTypeIdentifierHeartRate` с тем же `sourceName` и
  `startDate` в пределах ±2 минут от замера давления (при нескольких — ближайший).
  Пульс часов и прочий HR не берётся; замер без пульса даёт точки давления без пульса.
- День — календарная дата из `startDate` как записана (локальное время устройства).
- Точка = среднее за день, 1 знак после запятой (целое пишется целым).
  `lab`: «Самоизмерение (Apple Health)» для 1 замера, «Самоизмерение (Apple
  Health), среднее из N замеров за день» для N>1. Поля точки, `unit`, `ref`,
  статус — как у существующих точек ряда (`status` по `ref`, без нормы — `na`).

## Пропуски
- День уже есть в ряду с `lab`, начинающимся с «Самоизмерение (Apple Health)» →
  «уже внесено» (проверяется по каждому ряду отдельно; повторный запуск ничего не меняет).
- На день есть ручной замер в `vitals.json` → `bp[]` → «есть ручной замер», все три ряда пропускаются.
- `--since` — дни раньше даты не берутся.

## Запись
Перед записью `labs.json` перечитывается и копируется в `.intake-backups/`;
запись атомарная, через зеркало Synology с корнем `--root`. Имя ряда `exam_pulse`
приводится к «Пульс». Скрипт `vitals.json` не пишет никогда: ручные замеры вносит
человек формой на странице.
