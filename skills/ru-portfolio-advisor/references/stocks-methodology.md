# Методология анализа акций

Этот файл — про то, как делать Weekly Stocks Review и Single Stock Analysis. Пользователь держит ~25 активных российских имён + смотрит на портфель Invest Era. Работай с MOEX-бумагами, учитывай специфику (закрытость части отчётности, валютный режим, инфраструктурные риски по зарубежным листингам).

## Weekly Stocks Review

Цель: найти всё важное, что произошло за ~7 дней у эмитентов, чьи акции есть в портфеле или в планах. Проверить, не пропустил ли пользователь повод для срочной покупки/продажи.

### Шаг 1. Сбор тикеров (snapshot v2)

Реестр детерминирован (правило «Не выбирай тикеры сам» из SKILL.md):
1. **Активные позиции** — `holdings[]` where `asset_type == "stock"` и `status != "blocked"`
   (замороженные US-бумаги вне обзора — MOEX их не котирует).
2. **Планируемые** — `ie_actual.per_ticker` с `planned_share_pct > 0`, отсутствующие
   среди активных holdings.
3. **Кандидаты из IE** — `ie_summary.list_in_ie_not_in_portfolio`.

**Старт анализа** — тикеры с пометками пользователя в `ie_actual.per_ticker`:
`user_plan`, `user_status`, `user_note_ie`, `user_note_ai`. На них — самое плотное внимание.

> ⚠ До 2026-07 здесь стояли поля `metrics.active_stock_tickers` / `planned_stock_tickers` /
> `ie_not_in_active` / `stocks_with_action_notes` из парсера v1 — **в snapshot v2 блока
> `metrics` нет**. Реестр даёт только тройка выше; фаза веб-проверки обязана идти по этому
> же реестру (каждый тикер → строка в таблице покрытия R-COV, см. `report-template.md`),
> а не по «темам новостей».

### Шаг 2. Сбор событий за период (обычно 7 дней)

Для КАЖДОГО тикера проверь:

**Обязательный минимум:**
- Корпоративные новости (e-disclosure.ru): дивиденды, оферты, buyback, смена руководства, сделки M&A.
- Отчётность за период (если выходила) — МСФО/РСБУ.
- Существенные факты (сущфакты) в ЦРКИ.
- Движение цены более ±5% за день или ±10% за неделю — разобраться почему.

**Желательно:**
- Мнения T-Инвестиций / БКС / Альфа / SberCIB за неделю.
- Рейтинговые действия (если есть у эмитента рейтинг облигаций, это косвенный сигнал и по акциям).
- Тон Smart-lab/Пульса (для идентификации консенсуса).

**Макро-события, влияющие на сектор:**
- Нефть, газ, металлы — котировки и news flow (для нефтянки, металлургов, добычи).
- Ставка ЦБ и решения — банки, девелоперы, ритейл.
- Рубль — экспортёры vs внутренний спрос.
- Санкции и расследования — для публичных компаний с экспозицией на экспорт.

### Шаг 3. Классификация сигналов

Для каждой позиции поставь тег:

- **СРОЧНО ПРОДАТЬ** — фундамент сломался (дефолт, фрод, обнуление дивидендов без replacement), сильное негативное событие.
- **СРОЧНО ДОКУПИТЬ** — позитивное событие даёт большой upside (buyback, сильная отчётность, смена стратегии), бумага ещё не отреагировала или отреагировала недостаточно.
- **ДЕРЖАТЬ, НАБЛЮДАТЬ** — фоновые события, не меняющие картину.
- **ПОДУМАТЬ О СОКРАЩЕНИИ** — накапливаются негативные сигналы (замедление роста, смена guidance, новые регуляторные риски), но без немедленной угрозы.
- **НЕТ НОВОСТЕЙ** — ничего не произошло, доля актуальная.

### Шаг 4. Сравнение с заметками пользователя

В колонках "План" / "Статус" / "IE" / "AI" могут быть пометки типа "Продать", "Держать", "Докупка". Если твой вывод расходится с пользовательским — объясни почему. Если совпадает — подтверди и добавь свежий триггер.

### Шаг 5. Проверка макро-условий для типа "Акции"

Если за неделю накопились макро-сдвиги, которые влияют на весь класс:
- Резкое повышение/понижение ставки ЦБ (дисконтирование → переоценка акций).
- Бюджетные риски (доходы от нефтегаза, долгосрочные дефициты).
- Геополитические шоки.

В конце Weekly Stocks Review добавь блок "Стоит ли менять целевую долю акций (сейчас 40%)". Если аргументов нет — одна фраза "макро-условия не требуют пересмотра, остаёмся на 40%".

### Шаг 5а. Факторы, от которых зависит вердикт или условие, — проверить в этом прогоне

Если вердикт, порог или условие бумаги завязаны на фактор (золото у PLZL, нефть и газ у NVTK, курс у
экспортёров, ставка у банков и дивидендных историй), значение фактора берётся **в этом прогоне** и
пишется у бумаги с датой: «Brent $108 (21.10)», «GLDRUB_TOM 32 850 ₽/г (26.10)».

- ставка, инфляция, USD/RUB, CNY/RUB, Brent, RGBI, IMOEX — из последнего макроснимка (выжимка
  `prior_digest.py --macro-dir` выводит его с датой); снимок старше 7 дней — сказать об этом;
- золото в рублях — котировка `GLDRUB_TOM` MOEX ISS (валютный рынок, режим CETS:
  `https://iss.moex.com/iss/engines/currency/markets/selt/boards/CETS/securities/GLDRUB_TOM.json`);
  в долларах — вторично, с источником;
- не удалось — оговорка у бумаги «фактор X не проверен, данные на ДД.ММ», а не молчание.

Прецедент 26.10.2026: условие `plzl-above-1180-no-gold` требует цену золота, NVTK стоял в 1,1% от порога
продажи после +9,6% за неделю, а отчёт написал «валюта, нефть, золото не собирались» — при макроснимке
от 21.10 (USD/RUB −2,5%, Brent $108) в библиотеке.

## Single Stock Analysis (Mode 4)

Цель: глубокий разбор одного тикера по запросу. Mode 4 — **updater fundamental gate** (METH-2, `docs/investment/portfolio/new_met.md` §2.2).

### Три режима глубины (METH-2)

В зависимости от свежести stress / catalyst tree (лестница **только для Mode 4** — про право
называть числовой таргет в разборе одной бумаги; свежесть стресса для режимов 3 и 8 считается
по другой лестнице, `references/stress-reading.md` §2):

| Случай | Поведение Mode 4 |
|--------|-----------------|
| **Stress свежий (<4 нед) + catalyst tree есть** | Полный verdict с конкретным % target. Размер обоснован комбинацией fundamental gate + macro sizing. |
| **Stress есть, но stale (4–12 нед)** | Verdict с % target, но caveat «macro context может быть устаревшим, рекомендуется обновить stress перед действием». Числа со звёздочкой. |
| **Stress отсутствует или >12 нед** | **Fundamental-only verdict**: бинарное «тезис жив / на пересмотре / сломался» + рекомендуемое направление (buy/hold/trim), без числовых таргетов. В конце — «для решения о % запусти `portfolio-scenario-stress` или Mode 8». |

Mode 4 **никогда** не выдаёт committed % без macro-данных. Может дать направление + правдоподобный диапазон, не «купи 5–7 шт. до 5.5%».

### Структура анализа

1. **Бизнес-модель** — что делает компания, какая доля выручки по сегментам, география.
2. **Финансы** — ключевые метрики за последние 4-8 кварталов (Revenue, EBITDA, Net Income, Net Debt / EBITDA, FCF). Динамика и тренд.
3. **Оценка** — P/E, EV/EBITDA, EV/Sales forward (если аналитики дают прогнозы). Сравнение с собственной историей и с peer'ами на MOEX.
4. **Дивидендная политика** — что в дивполитике, какие ожидания на следующие 12м.
5. **Риски** — регуляторные, финансовые, операционные, санкционные. Не абстрактные, а конкретные.
6. **Драйверы роста** — что может двигать котировку в ближайшие 6-18 месяцев.
7. **Fundamental gate verdict (METH-2)** — `alive` / `under_review` / `broken` с обоснованием через 4 forward-чека (concentration, fundamentals delta, IE trust, catalyst EV). См. `analysis-process.md` Шаг 7.5. **Realised XIRR — не gate-чек**: это backward-диагностика, длинная просадка лишь триггерит проверку «циклический убыток vs сломанный тезис», а решение gate принимается по forward-метрикам (фундаментал, catalyst delivery).
8. **Позиция в портфеле пользователя** — сколько сейчас, какая доля, как соотносится с `planned_share_pct` (primary) и `ie_new_pct` (secondary). Иерархия: фундаментал → IE → planned.
9. **Рекомендация** — ДЕРЖАТЬ / ДОКУПИТЬ / СОКРАТИТЬ / ПРОДАТЬ с таргетом и горизонтом. При вердикте ДОКУПИТЬ / СОКРАТИТЬ / ПРОДАТЬ обоснование ОБЯЗАНО содержать хотя бы одну из четырёх форм (R11): ценовой ориентир («входить ниже 360 ₽»), yield-порог («при дивдоходности ≥10.2%»), событие-триггер с измеримым условием («после Q1 МСФО, если ЧП >X млрд»), явная price-agnostic установка с обоснованием («выходить по рынку без условий — тезис сломан»). ДЕРЖАТЬ без такого условия — допустимо.
10. **Решение по бумаге** — обязательный output: запись в блоке `decisions:` шапки отчёта (`key`, `verdict`,
    `target_pct`, `review_by`, `note`; формат — `references/output-templates.md` §«Решение по бумаге»). Гейт —
    проекция вердикта, срок гейта — `review_by` (7–180 дней; срок ставь от ближайшего катализатора). Нужен
    повторный полный разбор — `verdict: WATCH` (докупка закрыта до следующего решения). Файл решения
    пишет скрипт save-to-library при сохранении отчёта (Workflow N). Класс бумаги и дату листинга решение не несёт —
    они в справочнике бумаг (`security_digest.py`, блок `attrs`); правка — по слову владельца через save-to-library.

### Подсказки для частых случаев

Тикеры в скобках — **иллюстративные примеры**, состав портфеля и IE-модельки меняется. Если бумага не указана — определяй сектор по бизнесу эмитента (OKVED, сегменты выручки из МСФО) и применяй подсказку того сектора. Если бумага попадает в два сектора (холдинг) — применяй оба чек-листа.

**Зарубежные листинги и ГДР (в частности, GLTR, AGRO, OZON до переезда):**
- Проверь статус редомициляции.
- Посчитай риск блокировки / технических ограничений.
- Смотри, доступна ли бумага неквалам и может ли это измениться.

**Банки (в частности, SBER, SBERP, T, MBNK, SVCB, BSPB, VTBR, RENI):**
- Ключевые метрики: ROE, CIR, NIM, стоимость риска (CoR), достаточность капитала (CET1), дивиденды через МСФО прибыль и достаточность.
- Следи за решениями ЦБ по капиталу и регулированию.

**Нефтегаз (в частности, LKOH, ROSN, SIBN, TATN, GAZP, NVTK, SNGS):**
- Urals, Brent, дисконт Urals-Brent.
- Налоговая нагрузка — НДПИ, налог на доп. доход, демпфер.
- Отсечки дивидендов, объёмы добычи и переработки.

**Металлурги и добыча (в частности, GMKN, CHMF, NLMK, MAGN, PLZL, ALRS):**
- LME котировки, золото, алмазные рынки.
- Экспортные квоты, курс рубля.
- Для золотодобычи — себестоимость в USD, hedging.

**Ритейл и потребительский (в частности, X5, MGNT, LENT, MVID, FIVE, DSKY, BELU):**
- LFL-продажи, количество магазинов, средний чек.
- Инфляционный фон — потребительские цены vs продажи.

**Tech и IT (в частности, YDEX, OZON, HEAD, ASTR, POSI, DIAS, IVAT, DATA):**
- Темпы роста, юнит-экономика, маржинальность.
- Регуляторные риски (льготы, импортозамещение).

**Энергетика и утилиты (в частности, IRAO, HYDR, UPRO, LSNGP, RTKM, MRKC, MSRS):**
- Тарифы, RAB-регулирование, инвестпрограммы.
- Дивидендная политика (часто фиксированная).

## Взаимодействие с Invest Era

IE — один из инпутов, не истина. У пользователя регулярно встречаются **осознанные расхождения** с рекомендациями IE:
- Доля у пользователя может быть **выше** или **ниже** рекомендации IE — это осознанный выбор, который не нужно "исправлять" без веских аргументов (макро-сдвиг, смена фундаментала, новые риски).
- Чтобы идентифицировать такие позиции, сравни `Доля Реальная` и `IE New` по каждой активной бумаге. Расхождение в 2+ п.п. — вероятно осознанное, уточни в `План`/`Статус`/`IE`/`AI`, есть ли пометка пользователя.
- Если пометки нет, а расхождение заметное — можешь спросить: "Расхождение с IE по [TICKER] — осознанное или требует корректировки?" Но не переставляй молча веса в расчётах.

**Состав таких позиций меняется от периода к периоду** — не кэшируй предыдущие списки в голове, смотри каждый раз в свежий файл.

**Источник весов IE — строго файл пользователя** (колонки `IE New` и `IE Old`). Пользователь сам переносит актуальные цифры из закрытой подписки invest-era.ru. Не пытайся искать эти проценты в вебе — они за пейволом. Если `IE New = IE Old` или обе пустые — публичного изменения за период не было, так и отметь.

Обоснование изменений IE допустимо искать в открытых источниках:
- Публичный канал IE: t.me/s/usamarke1
- Профиль IE в Пульсе: tbank.ru/invest/social/profile/InvestEra
- Открытые статьи на invest-era.ru (часть материалов публичная)

Когда `IE New ≠ IE Old`, обязательно:
1. Укажи точное изменение в п.п. из файла (без домыслов): `T: 4% → 6%` и т.п.
2. Найди публичное обоснование IE в открытых каналах (если есть); если нет — напиши "IE обоснование за пейволом, восстановлено по публичному контексту".
3. Проверь, не изменились ли фундаменталы, которые IE могли учесть (отчётность, корп.события, рейтинги за период).
4. Дай своё мнение — согласиться или нет, с аргументами.

**Дифференцированный доверительный вес.** Не все рекомендации IE равноценны. Перед использованием `IE New` как сильного сигнала проверь категорию тикера по `references/invest-era-profile.md` (HIGH/MEDIUM/LOW). Систематические промахи IE по геополитике (16 мес. подряд) и санкционным бенефициарам (NVTK, FLOT, AFLT, UPRO) делают эти рекомендации ненадёжными даже при росте уверенности автора. С другой стороны, IE-negative-list по облигациям (CTRL за 4 мес. до снижения рейтинга, после уроков Борец) — реальная альфа, на которую стоит опираться даже сильнее, чем на брокерский консенсус.

**Системные дельты для контрсигнала по макро-прогнозам IE** (см. `invest-era-profile.md`):
- Ставка ЦБ: знак уклона сменился. 2024 — слишком ястребиный (−2...−3 п.п.); 2026 — слишком голубиный по темпу: добавлять ≈+0,25 п.п. на каждое заседание к траектории IE (направление MEDIUM, темп LOW)
- USD/RUB: ≤1 мес. — MEDIUM (по тренду; развороты против тренда — LOW); на месяцы вперёд — IGNORE. Дельта −25...−30 ₽ (2024–2025) в 2026 не подтвердилась
- IMOEX 12-мес target: дисконтировать −20...−30%; тайминг входа/разворота — игнорировать (0 пользы в 5 аудитах)
- Нефть: игнорировать (`oil-forecast` IGNORE с 2026-10)
- P(окончание СВО) и «стороны скоро договорятся» на горизонте >1 мес.: использовать Polymarket, не IE (IE +30–40 п.п. оптимизма). Тайминг событий ≤5 нед. с явным объяснением расхождения с рынком — MEDIUM
- Вероятности IE ≥75%: сбываются примерно в половине случаев — дисконтировать
- Золото «вершина цикла»: игнорировать (3/3 промаха)
- Выжимка синхронна с `references/trust-hierarchy.md` (перед Правилом 20); при правке — обе

**Условия пересмотра профиля IE.** Профиль построен на материале четырёх вебинаров и 10 регулярных обзоров 2024–2026 (5 аудитов, пересмотр 2026-10-02) в условиях СВО + ставки 14–21% + изоляции рынка. При срабатывании триггеров T1–T6 (см. правило 20 в `references/trust-hierarchy.md`) — переходи на режим «профиль под пересмотром», добавляй предупреждение в шапку ответа и снижай абсолютную силу следования IE-сигналам до получения нового аудита.

## Сайзинг при частичной заморозке акционной книги (gate-aware sizing)

Вынесено в `references/gate-aware-sizing.md` (2026-10-26): базу докупки считает `scripts/gate_aware_sizing.py`,
а 36 КБ обоснования читались в каждом обзоре акций и разборе бумаги. Читай этот файл, когда нужно
объяснить число скрипта («откуда сумма»), в режиме 3 (ребалансировка) и при правке правил сайзинга:
три варианта денежной базы, состав `F`, правило неразворота, лимиты концентрации, кэш при гейтах, L1-таргет.

## Анти-паттерны (не делай так)

- "По техническим индикаторам бумага перекуплена" — без контекста бесполезно.
- "Аналитики повысили таргет" — без имён аналитиков, даты и старого таргета бесполезно.
- "Компания показала сильную отчётность" — нужны конкретные цифры и сравнение.
- Общие фразы про "российский рынок дешёвый" — без привязки к P/E и историческим percentile.
- `advisor_verdict: BUY` с единственным условием типа «при подтверждённой дате ГОСА» без сопроводительного ценового/yield-диапазона — такое условие технически срабатывает даже если цена ушла выше выгодного диапазона. Любой BUY/TRIM/SELL по акции требует хотя бы одной из четырёх форм basis (см. R11 в `weekly-review-schema.md`).

### IE-дисциплина (режим 1 — обязательная секция; ретро-разбор 2026-07)

IE-следование статистически обыгрывало и рынок, и собственную селекцию пользователя —
опасен не IE, а **неосознанный дрейф** от модели. В каждом weekly stocks review (режим 1)
выводи секцию «IE-дисциплина» из `snapshot.ie_actual.per_ticker` + `ie_summary`:

1. **Отклонения ≥ 1.5 пп** (`|real_share_pct − ie_new_pct|`), **позиции вне IE**
   (`ie_summary.list_in_portfolio_not_in_ie`) и **IE-позиции, отсутствующие в портфеле**
   (`list_in_ie_not_in_portfolio`) — таблицей: тикер / факт / IE-цель / дельта / user_plan.
2. Для каждой строки проверь `user_plan` + `user_note_ie`/`user_note_ai`: есть осознанное
   решение → пометь «✓ решение», нет (null/KEEP без пояснения при большой дельте) →
   пометь **«⚠ дрейф без решения»** и в Action items предложи: либо записать план
   в Numbers (user_plan/user_note), либо закрыть отклонение сделкой.
3. Итоговая строка: `real_share_total_in_ie_pct` («N% акционной части следует IE») и
   количество дрейфов без решения. Если дрейфов нет — секция сжимается до одной строки.

Это дисциплина учёта решений, не запрет отклоняться: осознанное отклонение с записанным
планом — легально; молчаливый дрейф — нет.
