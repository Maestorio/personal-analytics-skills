# Critical Events List — когда обзор недели ставит «Нужен разбор» (METH-2)

См. `docs/investment/portfolio/new_met.md` §3.4 — двухуровневая модель critical events.

## Closed enum — без подтверждения

Событие из списка ниже → Mode 1 сразу ставит бумаге в обзоре `flags.gate_review_required: true`, код события
(snake_case latin) — первой фразой `advisor_verdict_basis`. Гейт становится «Нужен разбор», пока обзор новее
последнего решения по бумаге; снимает его новое решение разбора.

```yaml
closed_enum_no_confirm:
  - bankruptcy_filing
  - delisting_announce
  - sanction_against_issuer
  - fraud_charges
  - emergency_ceo_change
```

**Описание каждого:**

| Код | Триггер |
|-----|---------|
| `bankruptcy_filing` | Эмитент или его материнская/контролирующая структура подала заявление о банкротстве (Глава 11 / Глава 7 / российский 127-ФЗ). Источник: первичные документы (СРЮЛ, EDGAR, корп. раскрытия). |
| `delisting_announce` | Биржа объявила о делистинге эмитента или сам эмитент подал заявку. Источник: пресс-релиз биржи или эмитента. |
| `sanction_against_issuer` | Новые санкции конкретно против эмитента (не сектора) — US OFAC SDN, EU/UK sanctions list, СПЭБИ. Не путать с секторными санкциями (это headwind, но не critical). |
| `fraud_charges` | Официальные обвинения в крупном мошенничестве/манипуляции отчётностью против эмитента или его руководства. SEC/FCA/Минфин/СК. |
| `emergency_ceo_change` | CEO ушёл с формулировкой «по личным обстоятельствам» или арестован/задержан в течение последних 7 дней. Не плановая смена. |

Любое событие из enum ставит флаг без вопроса владельцу.

## Open trigger — с подтверждением владельца

Событие из списка ниже → Mode 1 **спрашивает владельца первым блоком ответа** («S&P понизил SBER на 2 ступени —
поставить «Нужен разбор»? да / нет») и ставит `flags.gate_review_required: true` только после «да»; код — первой
фразой `advisor_verdict_basis`.

```yaml
open_trigger_with_confirm:
  - quarterly_negative_fcf_2x        # 2 квартала подряд negative FCF
  - controlling_shareholder_legal    # суд/расследование против контр. акционера
  - insider_large_sale               # CEO/CFO/контр. акционер продал >20% пакета
  - rating_downgrade_2plus_notches   # понижение S&P/Moody's/АКРА на 2+ ступени
  - <free_text>                      # любой другой триггер — текст в обосновании
```

---

## Когда расширять enum

- Если `<free_text>` повторяется чаще 3 раз за полугодие — кодифицировать в open_trigger.
- Если владелец по open_trigger почти всегда отвечает «да» → перевести в closed_enum.
- Не добавлять в closed_enum без явного обсуждения с пользователем.

Обновления — вручную, через PR.
