# Model Routing для ru-portfolio-advisor

**Источник pricing/спецификаций:** [docs.claude.com / pricing](https://docs.claude.com/en/docs/about-claude/pricing) (проверено 12.08.2026).
**Контекст использования:** скилл работает через приложения Claude (claude.ai, мобильный/десктоп). Prompt caching не применяется на стороне пользователя — управляется бэкендом.
**Экономия на подписке Pro — в первую очередь квотная:** у Opus отдельный недельный счётчик, исполнение на Sonnet его не расходует. Этот файл — детальная версия глобального model-routing-канона репозитория (локальный override при упаковке).

## Сигналы для эскалации на Opus в любом режиме

Эскалируй с Sonnet на Opus, если в запросе или контексте:

1. Ребалансировка предполагает изменение веса LOW-тикера IE (NVTK, FLOT, AFLT, UPRO) на **≥2 п.п.**
2. Появилось рейтинговое действие или claim о национализации по позиции пользователя
3. Геополитический сдвиг (новые пакеты санкций OFAC/EU, эскалация конфликта)
4. Запрос «пересмотр плана» целевых долей валюта × тип
5. Обнаружен L-R-сигнал (реализовавшийся хвост) у позиций пользователя за период
6. Stock Quality Forward Review даже как часть многорежимного запроса
7. Сработал любой из триггеров T1–T6 (см. правило №20) — пересмотр профиля IE
8. В контексте уже >150K токенов и нужен глубокий синтез

## Сигналы для деэскалации на Haiku

Только для:
- Объяснений терминологии без файлов (YTM, TWR, дюрация, конвекс, оферта)
- Lookup курса валюты на дату (когда снапшот портфеля не нужен)
- Help-команды по самому скиллу

**Если запрос требует чтения хотя бы одного reference-файла — НЕ Haiku.** Проблема: после загрузки SKILL.md (~22K) + reference (10K) + истории диалога (5K) уже >40K, и сложного синтеза Haiku не вытянет.

## Экономика (грубая прикидка)

При типичном паттерне использования (4 weekly review + 1 rebalance + 2 single analysis в неделю + 1 stock quality forward review раз в квартал):

| Распределение запросов | Сейчас (всё Opus) | После routing |
|---|---|---|
| ~70% Sonnet (режимы 1, 2, 4, 5, 6, 7) | 100% × Opus rate | 70% × $0.6 (Sonnet/Opus ratio на input) |
| ~5% Haiku (методология) | 100% × Opus rate | 5% × $0.2 |
| ~25% Opus (режим 3 при флагах + 8 + многорежимные) | 100% × Opus rate | 25% × Opus rate |

**Ожидаемая экономия:** ~30–40% на токенах без потери качества на критичных режимах (3 при флагах, 8, многорежимные).

## Как пользователь переключает модель

**В приложениях Claude (claude.ai, мобильный/десктоп):**
- Селектор модели в верхней части окна чата
- Переключение применяется к новым сообщениям; история сохраняется

**Со стороны скилла:**
- Скилл сам не переключает модель — пользователь решает
- Если режим требует более мощной модели чем выбранная пользователем — **в шапке ответа добавить рекомендацию переключиться**:
  > «⚠️ Этот запрос относится к режиму 8 (Stock Quality Forward Review) — рекомендую переключиться на Opus для глубокого разбора. Текущий ответ на Sonnet будет менее детальным по per-security forward-тезисам.»
- Если пользователь выбрал Haiku на запрос, требующий >200K контекста — **в шапке ответа предупредить о возможных потерях**:
  > «⚠️ Для этого режима 200K-cap Haiku может быть тесен — возможны обрезания контекста. Рекомендую Sonnet.»

## Триггеры пересмотра самой таблицы routing

Каждый релиз новой модели Anthropic (следующие поколения Opus / Sonnet / Haiku) — пересмотреть таблицу с фактическими бенчмарками на портфельных задачах. Источник: [docs.claude.com — models overview](https://docs.claude.com/en/docs/about-claude/models/overview).

**Конкретные сигналы для пересмотра:**
1. Sonnet нового поколения показывает близкие к Opus результаты на длинных рассуждениях → возможно понижение Opus → Sonnet для режима 8
2. Haiku нового поколения получает контекст ≥500K → возможно использование для дополнительных простых режимов
3. Существенное изменение pricing (≥30% в любую сторону) — пересмотр баланса экономии
4. Изменение токенизатора новой модели — пересмотр оценки эффективной стоимости
