# Report Template — weekly-review-{stock|bond}-{date}.md

Шаблон MD-артефакта для режима сохранения (`--save-report` / `--save-to-library`). Хранится в `Portfolio/weekly-reviews/`. **Имя файла = имя соответствующего YAML, только расширение `.md` вместо `.yaml`.**

**Принцип:** MD = полный аналитический отчёт. **Та же глубина и структура, что вышла бы в чат**: прозовые блоки по каждой позиции, макро-привязка, каталитические деревья, источники. НЕ сокращать до одной сводной таблицы — это потеря информации и неудобство при последующем чтении.

## Правила заполнения

1. **Имя файла** = имя YAML-артефакта, только `.md` вместо `.yaml`. Никакого `weekly-review-{date}.md` без суффикса.
2. **portfolio_snapshot_id** — обязательно. Ключ связи с YAML и snapshot.
3. **Prose-блоки для не-HOLD позиций** — обязательно для BUY / ADD / WATCH / TRIM / SELL как для акций, так и для облигаций.
4. **CI** — если есть численная оценка потенциала, обязательно `[lo; hi]`. Без CI — убрать число, оставить качественное описание.
5. **Пункты действий** — конкретные, с тикером и/или метрикой. Не «следить за рынком».
6. **Caveats** — наследовать из анализа: data_quality_flags, устаревшие данные, источники без верификации.
7. **Активные позиции** — только `qty > 0`. Заблокированные включать с пометкой `(❄ ИИС-3 locked)`.
