# Иерархия источников

Пользователь биостатистик — приучен к первоисточникам. Этот файл определяет, какому источнику верить сильнее при конфликте, и куда идти за данными.

## Уровни доверия (по убыванию)

### Уровень 1 — Первичка (максимальное доверие)

Используй ВСЕГДА, когда речь о фундаменталах эмитента:

- **МСФО/РСБУ отчётность** эмитента — смотри на сайтах IR, e-disclosure.ru, corp-archive ЦРКИ.
- **Центр раскрытия корпоративной информации** (e-disclosure.ru) — сущфакты, решения советов директоров, дивидендные решения.
- **Раскрытия на Мосбирже** (moex.com/ru/listing/emission-docs.aspx) — проспекты, оферты, изменения в выпусках облигаций.
- **Пресс-релизы рейтинговых агентств**:
  - АКРА: acra-ratings.ru
  - Эксперт РА: raexpert.ru
  - НКР: ratings.ru
  - НРА: ra-national.ru
- **ЦБ РФ** (cbr.ru) — решения по ставке, пресс-релизы, ДКП-документы, Доклад о денежно-кредитной политике.
- **Росстат** (rosstat.gov.ru) — инфляция, промышленное производство, базовые макропоказатели.
- **Минфин** — план заимствований по ОФЗ, выпуски, аукционы.

### MOEX ISS API — первичный источник котировок, YTM и статических данных

Для всех цен, доходностей, дюраций, объёмов, статусов листинга **по умолчанию используй MOEX ISS API** (`iss.moex.com`). Это официальный API Мосбиржи, бесплатный, без авторизации, отдаёт XML/JSON/CSV. Веб-парсинг сайтов брокеров — fallback-уровень, не первый выбор.

**На практике ходи через скрипт `scripts/moex_quotes.py`** — он батчит до 10 SECID за запрос, автоопределяет биржевую доску по SECID или ISIN, нормализует ответ в единую схему. Пример:

```bash
python3 scripts/moex_quotes.py --from-portfolio /tmp/portfolio.json --json > /tmp/quotes.json
```

**Подробная документация — в `references/data-sources-priority.md`.** Там:
- Полный список досок и полей по типам (акция / ОФЗ / корп / замещайка / БПИФ).
- Fallback-цепочка на случай недоступности ISS (6 уровней).
- Схема выходного JSON скрипта.
- Таблица "какой источник для какой задачи".

Прямые curl-примеры, если скрипт недоступен:

```
# Акции (доска TQBR — основной режим T+), пакетно
https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQBR/securities.xml?securities=SBER,GAZP,LKOH&iss.meta=off&iss.only=securities,marketdata

# Облигации (ОФЗ — TQOB; корп и замещайки USD/EUR/CNY — TQCB; валюта через FACEUNIT)
https://iss.moex.com/iss/engines/stock/markets/bonds/boards/TQOB/securities.xml?securities=SU26238RMFS4&iss.meta=off

# БПИФ / ETF
https://iss.moex.com/iss/engines/stock/markets/shares/boards/TQTF/securities.xml?securities=SBMX,TGLD

# Автоопределение доски по SECID или ISIN
https://iss.moex.com/iss/securities.xml?q=SBER     # → primary_boardid=TQBR, is_traded=1
https://iss.moex.com/iss/securities.xml?q=RU0009029540   # → то же
```

**Правило:** если в первичке есть цифра, вторичные источники нужны только для интерпретации, не для перепроверки факта.

### Уровень 2 — Брокерская и независимая аналитика

Используй для мнений и таргетов. Указывай автора и дату:

**По акциям:**
- T-Инвестиции (tbank.ru/invest/research, ранее Тинькофф) — дневные обзоры, идеи.
- БКС Мир инвестиций (bcs.ru, bcs-express.ru) — регулярные обзоры, прогнозы.
- Альфа-Инвестиции (alfainvestments.ru) — аналитика по эмитентам.
- SberCIB (sberbank.com/investors) — макро + корпы.
- Велес Капитал (veles-capital.ru) — глубокие обзоры.
- Атон (aton-line.ru) — модели по крупным эмитентам.
- Финам (finam.ru) — обзоры, хотя уровень смешанный.

**По облигациям:**
- T-Инвестиции / БКС / Газпромбанк — регулярные облигационные обзоры.
- Cbonds (cbonds.ru) — справочные данные по выпускам, графики дох-сти, оферты.
- Rusbonds (rusbonds.ru) — альтернативный справочник.
- ДОМ.РФ, Совкомбанк — обзоры по ипотечным и банковским облигациям.

**По макро и ставке:**
- MMI Research (Михаил Матовников) — банковский сектор.
- Твёрдые цифры — аналитика по макро (Олег Шибанов, РШЭ).
- Softline Macro (Игорь Куземский, Дмитрий Полевой) — обзоры ставки.

### Уровень 3 — Деловые СМИ (для контекста)

Для новостного фона и быстрой проверки событий:
- Ведомости (vedomosti.ru)
- РБК (rbc.ru)
- Коммерсантъ (kommersant.ru)
- Интерфакс (interfax.ru)
- ТАСС экономика (tass.ru/ekonomika)

Используй для даты/факта события, но **не для финансовых метрик** — там часто ошибки и пересказы.

### Уровень 4 — Агрегаторы частных мнений (слухи, настроения)

**Smart-lab** (smart-lab.ru) и **Тинькофф Пульс** — источник слухов, настроений, альтернативных точек зрения.

Важно: пользователь явно сказал — уровень доверия этим источникам как к теханализу. То есть:
- Цитировать можно, но с оговоркой "мнение частных инвесторов".
- Никогда не использовать как единственный источник для решения.
- Использовать для идентификации консенсуса / расхождения ожиданий.

### Уровень 5 — Теханализ

Скользящие средние, RSI, уровни поддержки/сопротивления — как слабый сигнал на тайминг входа/выхода. Никогда не использовать как основу решения, только как дополнительный фильтр.

Источники: TradingView, Investing.com, Finam графики.

## Геополитика и санкции

- **Минфин США (OFAC)** — treasury.gov/policy-issues/financial-sanctions/specially-designated-nationals-and-blocked-persons-list-sdn-human-readable-lists
- **ЕС санкционный режим** — sanctionsmap.eu
- **Указы президента РФ** — kremlin.ru/events/president/news
- **Минфин РФ** по контрсанкциям.

Используй при оценке риска замещаек и активов с иностранным элементом (Ozon, Headhunter, GLTR и т.п. — там риски редомициляции и инфраструктурные риски).

## Что ДЕЛАТЬ при конфликте источников

1. Всегда отдавай приоритет первичке.
2. Если два брокерских обзора противоречат — цитируй оба, укажи даты, выдай собственное взвешенное суждение.
3. Если первичка противоречит брокерскому консенсусу — укажи это явно как "консенсус может быть устаревшим" или "консенсус не учитывает данные последнего отчёта".

## Что НЕ использовать

- Telegram-каналы с анонимными авторами без репутации.
- YouTube-блогеры как единственный источник.
- Обзоры, где не указана дата или автор.
- Прогнозы доходности без модели.

## Формат цитирования в отчёте

В конце каждого ответа секция "Источники" со ссылками:

```
Источники:
- МСФО Сбера 1Кв 2026 (sberbank.com/ir) — 29.04.2026
- БКС, "Стратегия на 2Кв 2026" (bcs-express.ru/...) — 15.04.2026
- ЦБ РФ, пресс-релиз по ставке (cbr.ru/...) — 25.04.2026
```

Для каждого ключевого утверждения в тексте — инлайн-ссылка через markdown.
