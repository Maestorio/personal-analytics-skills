# Correlation Rubric — оценка ρ для joint_from_axes

Используется в scenario-builder Шаг 5.5 для оценки корреляции между осями
Shell-матрицы перед вызовом `weights_from_axes(ev_x, ev_y, rho)` из
`scripts/scenario_axis_weights.py` (общий канон репозитория, встраивается при упаковке).

## Дефолт

**ρ = 0.0** при отсутствии аргументов в пользу зависимости осей (D6).
Это conservative prior — не утверждение о независимости, а отсутствие оснований.

## Исторические аналоги

| Пара осей | Направление | ρ | Обоснование |
|---|---|---|---|
| conflict_intensity × sanctions_intensity (RU-West) | positive | ~0.10 | Де-эскалация конфликта исторически сопровождается ослаблением санкций; эскалация — ужесточением |
| oil_price × rub_sanctions_exposure | positive | ~0.15 | При сильных санкциях нефтяные доходы падают независимо от цены нефти |
| us_rate_cycle × em_capital_flows | negative | ~−0.10 | Рост ставок ФРС → отток из EM; снижение → приток |
| geopolitics_escalation × budget_spending | negative | ~−0.05..0 | Слабая связь: военные расходы растут при любой эскалации |

## Правила оценки

1. **ρ > 0** (положительная корреляция): при HIGH на одной оси — повышается
   вероятность HIGH на другой. Усиливает однополюсные сценарии — те, где обе оси в одном полюсе (по канону §17 F4: A — обе HIGH, стресс-полюс; D — обе LOW, детант).

2. **ρ < 0** (отрицательная корреляция): при HIGH на одной оси — повышается
   вероятность LOW на другой. Усиливает антидиагональные сценарии (B и C).

3. **|ρ| ≤ 0.20** в большинстве реальных пар — сильная зависимость редка.

4. **Не используй |ρ| > 0.5** без явных исторических данных: при больших значениях
   `joint_from_axes` может вернуть отрицательные вероятности, что вызовет
   `AssertionError`. Для конкретных axes max-допустимый ρ зависит от ev_x и ev_y:
   при ev_x=0.73, ev_y=0.65 максимальный безопасный ρ ≈ 0.83.

## Формат вывода при opt-in

```
Оценка корреляции осей: ρ = 0.10
Обоснование: conflict_intensity × sanctions_intensity в контексте РФ-Запад
исторически положительно коррелированы (см. табл. выше).
Эффект: диагональные сценарии A и D получают небольшую надбавку вероятности.
```

## Когда рекомендовать ρ ≠ 0

Рекомендовать ненулевой ρ только если выполнено хотя бы одно условие:
- Оси являются классической парой из таблицы выше
- Пользователь приводит конкретный исторический аргумент с data
- Оба полюса осей механически связаны (one axis is a driver of another)
