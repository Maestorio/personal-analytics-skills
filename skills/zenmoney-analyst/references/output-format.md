# Формат ответа

Ориентир — телефонный экран: вывод первым, таблица, потом оговорки. Без вступлений и пересказа вопроса.

---

## Язык ответа: без внутренней кухни

Ответ читает человек, который не держит в голове устройство скилла и через неделю не вспомнит коды. Поэтому в тексте ответа:

- **Не называть инструменты, поля и коды.** Никаких `get_monthly_report`, `list_transactions`, `get_account_balances`, `TagTotal`, `factWithRefund`, `isInBalance`, `EXCHANGE_DIFF`, `merchantId`, «R8», «R4/R10», «Режим B». Писать, что это значит: «месячный отчёт ZenMoney», «итог отчёта», «счета, которые не входят в баланс», «курсовая разница».
- **Не описывать служебные шаги:** проверку контракта MCP, номера шагов («0a»), чтение карты. Если проверка контракта нашла расхождение — сказать словами, что это значит для цифр.
- **Источник остатков и курсов:** «текущие остатки и курсы ZenMoney», «остатки ZenMoney на 1 января», «курс ZenMoney на дату операции» — без имени инструмента.
- **Следующий шаг — словами:** «могу проверить траты со счетов вне баланса», а не «R8».
- **Роли счетов — по-русски:**

| Код в карте | В ответе |
|---|---|
| `liquid` | кеш |
| `fx-liquid` | валютный кеш |
| `external` | внешний периметр (счета в зарубежных банках) |
| `shared` | общий счёт |
| `trip-wallet` | остатки валют с поездок |
| `deferred` | вклады до срока |
| `investment` | инвестиции |
| `ignore` | не учитываются |

Технические детали (какие вызовы, как сверялось) — только если пользователь спросил «как считал».

---

## Структура

1. **Вывод одной-двумя фразами** (число и смысл).
2. **Таблица или список** — по месяцам, категориям или счетам.
3. **Охват и допущения** — 3–5 пунктов (см. ниже).
4. **Что не проверял** — только если это влияет на вывод.
5. **Один следующий шаг**, если он вытекает из результата (не больше одного).

Длина: простой вопрос — 1–3 предложения; анализ — 1–2 экрана. Дольше — только по просьбе.

---

## Числа

- Деньги в **тыс. ₽ с одним знаком после запятой**; суммы меньше 10 тыс. — в рублях.
- Валюта поездок — в исходной валюте и ориентировочный рубль («≈ 80 тыс. ₽ по курсу отчёта»).
- Проценты — целые, кроме значений меньше 10% (один знак).
- Одна и та же величина — везде с одним округлением.
- Дельта с явным знаком: `+12,3`, `−4,5`.
- **Периоды длиннее месяца — в среднем за месяц, итог за период в скобках:** «Питание 74,7 тыс/мес (224,0 за период)». Так периоды разной длины сравнимы, и большие суммы не пугают. Неполный месяц: среднее считать по фактическому числу дней (например, 2,8 месяца для июль — 24 сентября) и сказать об этом одной строкой.

---

## Сверка перед выводом

- [ ] Сумма строк верхнего уровня = итог отчёта (±1 ₽).
- [ ] Итоговая строка = сумма показанных строк (с учётом округления).
- [ ] Переводы и курсовая разница не попали в доходы и расходы.
- [ ] «Корректировка» вынесена отдельно.
- [ ] Очищенный итог = итог отчёта − показанные исключения (каждое исключение — своей строкой).
- [ ] Неполный месяц помечен.
- [ ] Ни одного `externalIds`, номера карты или счёта в ответе.

Если какая-то проверка не прошла — не показывать таблицу, сначала найти причину.

## Обязательные оговорки (по ситуации)

| Ситуация | Что сказать |
|---|---|
| Неполный текущий месяц | «Данные на N-е число» |
| Ответ по истории | «По сохранённым итогам месяцев (дата); <текущий месяц> — по ZenMoney на N-е число; в номинале». Месяц, пересчитанный после правки, — назвать. Число обращений к ZenMoney не называть |
| Сравнение разных лет | Инфляцию не учитывал; категории могли поменяться |
| Валютные траты | Курс на дату операции (или отчёт); текущий — только если на дату курса нет, и назвать это приближением |
| Поездка не выделена | Теги в отчёте не видны; поездка смешана с бытовыми |
| Остатки или капитал на прошлую дату | Восстановлено по текущим записям ZenMoney; счета, обновляемые вручную (брокерские, крипта), могут быть неточны |
| Остатки «сейчас» | Включают ещё не проведённые банком операции (холды), если они заметны |
| Отчёт считает только счета в балансе, проверка охвата не проводилась или старше 90 дней | «Траты со счетов вне баланса в отчёт не попадают; за этот период не проверял» |
| Контракт MCP не проверялся больше 90 дней или найдено расхождение | Одной строкой: что именно и что это значит для цифр |
| Совместный счёт | Взносы партнёра — не доход; расход общего счёта включён целиком. «Мой расход» = весь − сальдо расчётов с партнёром |
| Возвраты, кешбэк, компенсации | В очищенный доход не входят; показаны отдельными строками. Смешанная категория без разбивки — назвать это |
| Вопрос про цены | Суммы по категории не показывают цены; дать таблицу по одинаковым точкам с числом покупок, назвать слабые места (мало покупок, состав заказа неизвестен) |
| «Месяц без поездок» | Проверено по тегам и датам операций; если поездка нашлась, назвать и указать, сколько дней дома осталось |
| Отчёт за месяц пуст | Цифры собраны по операциям (счета могли быть вне баланса) |
| Запас по времени | Уровни (кеш → + валютный кеш → + внешний периметр), курс пересчёта валют (текущий), доход, базовый расход, вычтенное; остатки по отдельным счетам не выводить |
| Ответ посчитан кодом по файлу ответа MCP | Не нужно говорить; но если часть страниц не прочитана — сказать явно |

## Чего не делать в ответе

- Не давать рекомендаций по инвестициям и вкладам.
- Не сообщать об изменении в ZenMoney, пока оно не подтверждено перечитыванием; показывать «было → стало».
- Не «успокаивать» и не оценивать («много», «мало») — только цифры и допущения. Если пользователь спрашивает оценку, сравнивать с его же периодами.
- Не выдумывать причины: если категория выросла, показать, из каких подкатегорий; если не видно — сказать «в отчёте не видно».
- Не повторять всю таблицу в тексте: только выводы.
