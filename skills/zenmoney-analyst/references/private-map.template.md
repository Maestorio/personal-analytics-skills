> **Карта тонкая:** только решения пользователя, которых нет в ZenMoney. Названия, валюты, банки, страны счетов и названия категорий скилл берёт из MCP — в карту их не переписывать (кроме подписи к ID для человека).

## Роли счетов: исключения из правил

Роль каждого счёта скилл считает по правилам (`data-schema.md` §4). Здесь — только счета, где правило ошибается.

Роли: `liquid` — кеш (уровень 1), `fx-liquid` — валютный кеш (уровень 2), `external` — внешний периметр (уровень 3), `shared` — общий счёт, `trip-wallet` — валюта с поездок, `deferred` — вклады до срока, `investment` — инвестиции, `ignore` — не учитываются.

| Счёт (подпись) | ID (полный) | Роль | Почему не по правилу |
|---|---|---|---|
| `<подпись>` | `<uuid>` | shared | общий счёт с партнёром |
| `<подпись>` | `<uuid>` | liquid | накопительный, но в ZenMoney тип «вклад» |

## Неиспользуемые счета (не закрыты)

Счета, которыми пользователь больше не пользуется, но не закрыл. Аудит их **не упоминает**, пока нет движения; движение после даты — показать как неожиданное.
