# Source Strategies — Стратегии доступа к архивам

## Принцип: архив > агрегатор > поиск по упоминаниям

Приоритет доступа (от лучшего к худшему):
1. Прямой архив источника (канал, сайт, RSS)
2. Агрегатор с временными метками (TGStat, Wayback Machine)
3. Поиск по упоминаниям («что говорил X о Y») — только запасной

Причина: поиск по упоминаниям возвращает memorable predictions —
события, которые оказались резонансными (громкие попадания или провалы).
Это смещает выборку в сторону крайних значений.

---

## Telegram-каналы

**Лучший доступ:**
- `web_fetch("https://t.me/s/[username]")` — публичный архив канала
- Постранично, добавляя `?before=[post_id]` для пагинации назад во времени
- TGStat: `web_fetch("https://tgstat.ru/channel/@[username]/stat")` —
  статистика и топ-посты (осторожно: топ-посты = bias)

**Хронологический обход:**
1. Получить последние посты через `t.me/s/[username]`
2. Найти самый ранний ID в текущей странице
3. Запросить `t.me/s/[username]?before=[id]` для предыдущего периода
4. Повторить для 3–4 временных окон

**Ограничения:**
- Приватные каналы недоступны → фиксировать в `source_note`
- Посты старше ~1000 могут быть недоступны через t.me/s/ →
  использовать Wayback Machine

## Сайты и блоги

**Стратегия:**
- Найти страницу архива или тег/категорию «прогнозы» / «forecasts»
- RSS-лента если доступна: `web_fetch("[url]/feed")` или `[url]/rss.xml`
- Sitemap: `web_fetch("[url]/sitemap.xml")` — список всех публикаций с датами

**Хронологический обход:**
- Сортировать публикации по дате, брать из разных периодов
- Не ограничиваться первой страницей поиска

## Sell-side отчёты (банки, брокеры)

**Стратегия:**
- `web_search("[банк] [год] strategy outlook forecast")` — годовые отчёты
- `web_search("[банк] [год] Q[квартал] review")` — квартальные
- Искать PDF-версии напрямую, fetch их
- Альтернатива: страница IR или research на сайте банка

**Особенность:** sell-side часто публикует точечные прогнозы с явными
числовыми целями (target price, year-end forecast) — хорошо пригодны
для falsifiability.

**Cluster note:** sell-side одной юрисдикции (напр. российские брокеры)
разделяет регуляторные ограничения и публичный нарратив. При сравнении
нескольких sell-side источников — учитывать кластерный bias.

## Think tanks (CFR, Brookings, Carnegie, Stratfor, CSIS, RAND, IISS)

**Стратегия:**
- Страница публикаций с фильтром по году: `[url]/publications?year=[год]`
- Поиск по тегу «forecast» или «outlook»
- Ежегодные outlook-документы — концентрированный источник прогнозов

**Пример:**
```
web_fetch("https://www.cfr.org/reports?topic=forecast")
web_fetch("https://www.brookings.edu/search/?s=forecast&start_date=2023-01-01")
```

**Cluster note для геополитики:** западные think tanks (CFR, Brookings, CSIS,
RAND, ASPI) разделяют общую аналитическую традицию и часто цитируют друг
друга. Их совпадающие позиции — не независимые сигналы. IISS позиционируется
как более нейтральный; Carnegie варьируется по офису. Фиксировать
`cluster_note: западный think tank` в шапке коллекции.

## Twitter/X (аккаунты аналитиков)

**Стратегия:**
- `web_search("site:twitter.com [username] forecast predict 2024")` или
  `site:x.com`
- Twitter/X API недоступен напрямую — использовать web_search
- Nitter-зеркала если доступны: `web_fetch("https://nitter.net/[username]")`

**Ограничение:** Twitter очень плохо индексируется хронологически.
Фиксировать как `access_limited` если покрытие неполное.

---

## Подкасты и YouTube

**Стратегия:**
- Искать транскрипты эпизодов: `web_search("[канал] [эпизод] transcript")`
- Автоматические субтитры YouTube: доступны через специализированные сервисы
- Часто есть текстовые резюме на сайте подкаста или Substack

**Ограничение:** транскрипты часто неточны, прогнозные тезисы могут быть
размыты в разговоре. Принимать только чёткие утверждения.

## Государственные статистические институты (EIA, BEA, Eurostat, NBS)

**Стратегия:**
- Архив релизов / outlook-документов на официальном сайте
- EIA STEO: `web_fetch("https://www.eia.gov/outlooks/steo/archives/[mmmYY].pdf")`
- BEA: GDP releases по кварталам, доступны напрямую
- Eurostat: euro-indicators releases с таймстемпами

**Особенность:** государственные институты публикуют point-estimates без
verbal confidence — колонка `confidence_stated` обычно остаётся `—`.
Зато прогнозы максимально falsifiable: чёткое число + чёткий период.

**Cluster note:** государственные институты не взаимонезависимы с
коммерческими прогнозистами одного периода — пересекающаяся методология
(например, EIA использует S&P Global macroeconomic model). Фиксировать.

## Wayback Machine (архив удалённого контента)

```
web_fetch("https://web.archive.org/web/[YYYYMMDD]*/[url]")
```

Используй когда:
- Сайт или страница удалена
- Нужна версия на конкретную дату
- Оригинальный контент изменён после публикации

---

## Флаги ограниченного доступа

Если архив недоступен полностью — фиксировать в шапке вывода:
```
source_access: limited
source_note: "Архив канала закрыт после 2023-06. Использован поиск по упоминаниям — возможен memorable-bias."
```

Это не блокирует вывод, но предупреждает аудитора (retrospective-forecast-audit)
о потенциальном смещении выборки.
