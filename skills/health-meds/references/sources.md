# Источники справки и правила уверенности

Лестница источников для `health-meds`. Провенанс-гейты **не обходить**: если
страница не открылась — источник недоступен, а не «я и так помню». Цена ошибки
здесь — не кривой отчёт, а человек, поверивший выдумке про своё лекарство.

## Лестница

| Тир | Источник | Что берём | `confidence` |
|---|---|---|---|
| **1 — первичка** | **ГРЛС** (`grls.rosminzdrav.ru`) — госреестр РФ, официальная инструкция | всё: МНН, класс, показания, взаимодействия, предупреждения | `high` |
| | **DailyMed** (`dailymed.nlm.nih.gov`) — метки FDA | то же для импортных/зарубежных | `high` |
| | **SmPC / EMA** (`ema.europa.eu`) | то же для европейских | `high` |
| | Сайт производителя — **только страница инструкции** конкретного препарата | то же | `high` |
| **2 — авторитетная вторичка** | **РЛС** (`rlsnet.ru`), **Vidal** (`vidal.ru`) | всё, если первичка не нашлась | `medium` |
| | **drugs.com**, **MedlinePlus** | взаимодействия, класс | `medium` |
| **3 — навигация** | Википедия, аптечные каталоги, агрегаторы | **только чтобы найти первичку** | — |
| **Никогда** | форумы, отзывы, блоги, «народные» справочники, ИИ-сводки в выдаче | — | — |

Тир 3 — не источник факта. Из него можно взять МНН, чтобы найти препарат в ГРЛС,
но записать в файл со ссылкой на википедию нельзя.

## Правила `confidence`

| Значение | Когда |
|---|---|
| `high` | факт из тира 1 и подтверждён вторым проходом (§3 процедуры) |
| `medium` | только тир 2; **или** тир 1, но источники расходятся и расхождение разрешено в пользу первички; **или** препарат опознан по названию с небольшой неоднозначностью |
| `low` | расхождение не разрешено; данные косвенные; форма/дозировка не сходится с `user`-полями |

⚠ **`high` на одной вторичке — blocking, а не совет.** `validate_meds.py` смотрит
домены `ref_meta.sources`: если ВСЕ они из списка тира 2 — запись не проходит.
Это не перестраховка, а разбор реального промаха: прогон 2026-07-17 проставил `high`
семнадцати записям по РЛС и Vidal, ни разу не открыв ГРЛС; правило жило только в
этом файле и модель его не удержала. Незнакомый домен (инструкция производителя на
его же сайте — `akrikhin.ru/…/Diakarb.pdf`) трактуется в пользу записи: заранее
перечислить такие домены нельзя.

Практический вывод: **хочешь `high` — открой ГРЛС**. Не открыл — `medium`, и это
нормально: `medium` не ругательство, а честное «взято из авторитетного пересказа
инструкции».

`confidence` — на запись целиком, по слабейшему из заполненных полей. Половина
полей `high`, одно `medium` → у записи `medium`.

Не подтверждено ничем — поле остаётся пустым (`null` в `enrich`), а не заполняется
с `low`. `low` — про «источник есть, но шаткий», а не про «я предположил».

## Российская специфика

- **Торговое название ≠ МНН.** «Мезим» → панкреатин, «Но-шпа» → дротаверин,
  «Экофурил»/«Энтерофурил» → нифуроксазид (разные бренды, одно вещество — это
  нормально и стоит упомянуть в отчёте).
- Один бренд у разных производителей может иметь **разный состав** — сверяйся с
  дозировкой и формой из `user`-полей; не сходится → вопрос пользователю.
- **БАД — не лекарство**: у него нет инструкции в ГРЛС и часто нет доказанных
  показаний. Так и писать («БАД, регистрационного показания нет»), не подтягивать
  показания «по действующему веществу» как у лекарства.
- Комбинированные препараты (Терафлю, Синупрет): перечислять все действующие
  вещества, взаимодействия считать по каждому.

## Взаимодействия

Проверять **конкретные пары** среди `taking: true`, а не «взаимодействия
препарата вообще» — иначе в файл уедет простыня, которая к этой аптечке не
относится.

Порядок: interaction checker (drugs.com) как **навигатор** — что вообще искать →
подтверждение пары по инструкции обоих препаратов (тир 1) → запись прозой с
указанием, с чем именно и что происходит.

Найдено значимое взаимодействие — это **повод сказать пользователю в отчёте**,
отдельно и заметно, а не только строкой в JSON. Но формулировка — «инструкция
указывает X», не «тебе нужно перестать принимать Y».
