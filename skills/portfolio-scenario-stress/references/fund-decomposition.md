# Fund Decomposition

> **Единицы β:** политические факторы `sanctions`/`geopol` — п.п. цены на 1.0
> интенсивности (шкала −1…+1), рыночные — п.п. на 1% движения фактора.
> Полный контракт и почему это критично — `sector-sensitivities.md`
> → «Контракт единиц».

Фонды (ETF, БПИФ) перед применением sensitivity matrix раскладываются на underlying активы. Применение матрицы напрямую к «фонду» как к сектору невозможно.

## TGLD (Тинькофф Золото / Т-Золото)

**Тип:** БПИФ, отслеживает физическое золото.
**Underlying:** физическое золото (100%).
**Биржевая торговля:** в RUB на Мосбирже, но привязано к gold spot (USD) × USD/RUB.

**Sensitivity:**

| Фактор | β | Confidence | Комментарий |
|--------|---|------------|-------------|
| usdrub | +0.95 | HIGH | Золото номинировано в USD; рублёвая стоимость ≈ gold_USD × USD/RUB |
| cnyrub | +0.20 | MEDIUM | Вторичный эффект через FX |
| gold_price_usd | +0.95 | HIGH | Если в сценарии указан % изменения цены золота |
| brent | +0.05 | LOW | Незначительный |
| rate | -0.10 | LOW | Косвенный (через золото как alt investment) |
| sanctions | -5 | LOW | Минимальный; БПИФ доступен внутри РФ |
| geopol | +10 | MEDIUM | Золото — safe haven; но рублёвый эффект ограничен |

**Ключевое:** доминирующий фактор — USD/RUB. При ослаблении рубля на 15% → TGLD вырастет ~14–15% в рублях.

**При сценарии без gold_price:**
```
Δprice_rub_pct ≈ usdrub_pct_change × 0.95
```

**При сценарии с gold_price и usdrub:**
```
Δprice_rub_pct ≈ gold_price_pct_change + usdrub_pct_change
(перемножение: (1 + gold_chg) × (1 + fx_chg) − 1, но для малых изменений — аддитивно)
```

## SBMX (Сбер — Индекс МосБиржи)

**Тип:** БПИФ, отслеживает IMOEX (Индекс Московской Биржи).
**Underlying:** полная репликация IMOEX (~41 акция с весами MOEX).

**Подход:** не применять отдельную sensitivity, а суммировать sensitivity через веса индекса.

**Веса IMOEX (топ-10, ≈70% индекса, актуально на 2025):**
| Тикер | Вес | Сектор |
|-------|-----|--------|
| LKOH | ~14% | oil&gas |
| SBER | ~14% | banks |
| GAZP | ~8% | oil&gas |
| NVTK | ~6% | oil&gas |
| YDEX | ~5% | tech |
| ROSN | ~5% | oil&gas |
| GMKN | ~5% | metals_pgm |
| T | ~4% | banks |
| TATN | ~4% | oil&gas |
| CHMF | ~3% | steel |

**Расчёт sensitivity SBMX:**
```python
# Для каждого фактора:
β_sbmx_factor = sum(weight_i × β_sector_i_factor
                    for each major holding in IMOEX)

# Упрощённая оценка (достаточна для этого скилла):
β_sbmx_brent  ≈ +0.45  (нефтяники ~37% индекса)
β_sbmx_usdrub ≈ +0.30  (экспортёры доминируют)
β_sbmx_rate   ≈ -0.25  (широкий рынок)
β_sbmx_sanctions ≈ -20
β_sbmx_geopol ≈ -18
```

**Confidence:** MEDIUM для всех факторов (IMOEX = усреднение по многим секторам → сглаживание).

**Примечание:** если пользователь держит SBMX и крупные позиции по отдельным нефтяникам одновременно — учитывать overlap. SBMX уже содержит LKOH/ROSN через веса → добавление отдельных нефтяников увеличивает oil&gas concentration выше номинальной доли.

## Рентал ПРО (ЗПИФ Рентальная недвижимость)

**Тип:** ЗПИФ (закрытый паевой инвестиционный фонд), коммерческая недвижимость.
**Underlying:** склады класса A, логистические центры (преимущественно).
**Характеристика:** менее ликвидный, чем БПИФ; рыночная цена может отклоняться от NAV.

**Sensitivity:**

| Фактор | β | Confidence | Комментарий |
|--------|---|------------|-------------|
| rate | -0.40 | HIGH | Аренда коммерческой недвижимости напрямую конкурирует со ставками |
| usdrub | +0.10 | LOW | Незначительный |
| brent | +0.05 | LOW | |
| sanctions | -10 | LOW | |
| geopol | -15 | MEDIUM | Неопределённость снижает спрос арендаторов |

**Дополнительный эффект ставки:**
ЗПИФ недвижимости особенно чувствителен к ставке, потому что:
1. Арендаторы при высоких ставках переносят инвестрешения → вакантность растёт
2. Дисконтирование денежных потоков фонда ухудшается
3. Конкуренция с депозитами: при ставке >15% инвесторы выходят из ЗПИФ → давление на цену пая

## TMOS (Тинькофф Индекс МосБиржи / Т-MOEX)

**Тип:** БПИФ, аналог SBMX, отслеживает IMOEX.
**Sensitivity:** идентична SBMX (см. выше).

## Другие фонды (общий принцип)

Если в портфеле есть фонд, не перечисленный выше:

1. Определить underlying из названия и документации
2. Если облигационный фонд → применять bonds-sensitivity.md
3. Если смешанный фонд (акции + облигации) → разложить по дюрации и секторам примерно
4. Если непонятен underlying → флаг `⚠️ FUND_UNKNOWN_UNDERLYING`, использовать SBMX как proxy с LOW confidence

**Для золотых фондов (помимо TGLD):** SLVR, GOLD — аналогично TGLD.

## Флаги для выхода

| Ситуация | Флаг | Действие |
|----------|------|---------|
| Дюрация SBMX/IMOEX веса не актуальны | `⚠️ IMOEX_WEIGHTS_APPROX` | Использовать упрощённые веса |
| Фонд не в списке выше | `⚠️ FUND_UNKNOWN_UNDERLYING` | Proxy = SBMX |
| Рентал ПРО: цена пая ≠ NAV | — | Использовать `value_rub` из снапшота как есть |
| TGLD при gold_price в сценарии | `ℹ️ GOLD_PRICE_APPLIED` | Указать в confidence note |
