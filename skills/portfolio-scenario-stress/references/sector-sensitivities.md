# Sector Sensitivities Matrix

Sensitivity matrix: сектор × фактор → β (коэффициент чувствительности).

**Область применения:** только `asset_type: "stock"`. Облигации → `bonds-sensitivity.md`, фонды (TGLD, SBMX, Рентал ПРО, TMOS) → `fund-decomposition.md`. SU-тикеры и замещайки — тоже в `bonds-sensitivity.md`.

Тикер без маппинга в этой таблице → проверить другие reference-файлы перед флагом `⚠️ UNMAPPED`.

---

<a id="контракт-единиц"></a>
## Контракт единиц (обязателен к соблюдению)

**β — процентные пункты цены на ОДНУ единицу фактора в его собственной единице.**
Одно правило на все факторы, без исключений:

| Фактор | Единица фактора | β = 1.0 означает |
|---|---|---|
| `brent`, `usdrub`, `cnyrub`, `xauusd` | 1% изменения | +1 п.п. к цене бумаги |
| `cbr_rate` | 1 п.п. ставки | +1 п.п. к цене бумаги |
| `sanctions`, `geopol` | 1.0 интенсивности (шкала −1…+1) | +1 п.п. к цене бумаги |

Отсюда политическая бета банков в таблицах ниже = **−35**, а не −0.35.

> ⚠️ **Почему это критично.** `compute_per_position.py` складывает `Σ β × factor`
> в п.п. и шкалу не различает. Долевая запись («доля цены на единицу») отличается
> ровно в 100 раз и **молча зануляет весь политический канал**. Реальный случай:
> прогоны `stress-2026-07-15` и `-07-23` получили `SBER.sanctions = −0.35` →
> полная разрядка (интенсивность −0.9) сдвинула SBER на **+0.32 п.п.** вместо
> +31.5, из-за чего порядок сценариев перевернулся и «затяжная осада с
> ужесточением санкций» стала лучшим миром для портфеля (+31.0% против +24.1% у
> большой сделки на h24). Прогон `-07-02` на тех же данных стоял в п.п.-шкале
> (`SBER.sanctions = −12.0`) и давал осмысленный порядок D > C > B > A.
> Скрипт отказывается считать при заниженной шкале (`--political-scale-check`,
> по умолчанию `error`). Проверка **показная**, не по максимуму портфеля: частичная
> миграция (домножили банки, забыли экспортёров) — самый вероятный сценарий ошибки,
> и одна верная запись не должна разоружать проверку для остальных. Нижний порог
> применяется **только к долевым инструментам**; у облигаций бета законно дробная.
> Класс актива берётся из `asset_type` в **priors** (приоритет), затем из снапшота.
> Приоритет у priors намеренно: `asset_type` снапшота грубый — в живых данных это
> ровно `stock` / `bond` / `fund`, и под `fund` лежат в том числе ОБЛИГАЦИОННЫЕ
> фонды (TLCB, SBGB), чьи беты считаются по `bonds-sensitivity.md` и законно
> дробные. Голый `fund` и незнакомая строка → проверка по бумаге пропускается
> с warning. Словарь, который понимает гард: `stock` / `bond` / `bond_fx` /
> `fund_equity` / `fund_gold` → классифицируются; `bond_fund` → долговой;
> `fund` / `other` → неоднозначно, warning.

**Что такое интенсивность ±1.** Максимальный правдоподобный сдвиг относительно
**сегодняшнего** состояния на горизонте анализа — не повторение февраля-2022 с
чистого листа. `+1` — самый жёсткий пакет, который реально ввести сверх уже
действующих; `−1` — снятие санкций/разрядка в максимальном рассматриваемом
объёме; `0` — статус-кво. Поэтому β банков = −35, хотя фактическая просадка SBER
в 2022 была −70…−90%: это инкремент от текущего состояния, а не полный шок.

<a id="позиция-на-санкционной-шкале"></a>
## Позиция на санкционной шкале (обязательна для санкционно-чувствительных бумаг)

β в таблицах ниже описывает **полный переход** бумаги с нулевой позиции
(санкциями не тронута) на единичную (максимально заблокирована). Но бумага уже
где-то на этой шкале стоит, и от позиции зависит, сколько хода ей осталось:

```
sanctions_position ∈ [0, 1]    # поле позиции в betas-priors.json
effective = clamp(position + intensity, 0, 1) − position
effect    = β_sanctions × effective
```

Асимметрия «ужесточение слабее, снятие сильнее» берётся **из позиции**, а не из
двух разных бет: у заблокированной бумаги почти нет хода дальше, но есть весь ход
обратно; у нетронутой санкционного дисконта в цене нет и высвобождать нечего.

| position | Признак | Примеры |
|---|---|---|
| 0.85–0.9 | под блокирующими санкциями, расчёты и активы отрезаны; остаточный ход — вторичные санкции и правоприменение по контрагентам | SBER, VTBR, FLOT |
| 0.5–0.7 | секторальные ограничения либо блокировка отдельных проектов | NVTK (Арктик СПГ-2), GAZP |
| 0.2–0.4 | задевает косвенно: платежи, логистика, контрагенты | экспортёры без прямых мер, часть IT |
| 0.0–0.1 | внутренний бизнес, прямых мер нет | сетевые, локальный ритейл, девелоперы |

Поле опционально: не задано → расчёт по полной интенсивности в обе стороны
(прежнее поведение), но `compute_per_position.py` предупреждает по бумагам с
|β_sanctions| ≥ 20. `geopol` позиции **не имеет** и не клампится — это страновая
риск-премия, она давит и отпускает весь рынок сразу.

### Класс экспозиции — чем задаётся модуль β

| Класс | Признак | β_sanctions | Статус |
|---|---|---|---|
| Прямая блокировка бизнеса | валютные расчёты, иностранные контрагенты, экспортная выручка | **−35…−40** | **калибровано** |
| Секторальные ограничения | сбыт переориентируем, ограничения долговые/технологические | −15…−25 | интерполяция |
| Косвенная экспозиция | внутренний спрос, импорт компонентов | −5…−10 | допущение, прямых измерений нет |

> **Калибровка верхнего класса** — собственный замер на данных MOEX (2026-08-03,
> код и оговорки: `tools/research/pss-4-sanctions/`): назначение SDN на чистую
> бумагу (Rusal, En+, 06.04.2018) стоило **−33.7%** в окне [0;+1] и **−43.1%**
> в [0;+5]; DiD против корзины металлургов −39.0%, рандомизационный p < 0.001.
> Опубликованные Dovbnya (2020) ≈ −20% по шести целям волны воспроизводятся при
> сопоставимом составе портфеля. Обратный ход: анонс снятия 19.12.2018 дал
> **+23.1%** [0;+1] (p = 0.021), а фактический делистинг 27.01.2019 — **ноль**
> (−4.4%, p = 0.43). Релиф отыграл ≈ 59% нанесённого ущерба.
>
> Отсюда же — правило про предвосхищённость: движение забирает **первый
> достоверный сигнал**, формальное исполнение не даёт ничего. Если сценарий уже
> ушёл в консенсус, остаток хода мал, а на самом событии может быть отрицателен.

Строки таблиц ниже, где сектор относится к верхнему классу (нефтегаз-экспортёры,
металлурги-экспортёры, FLOT, банки внешних расчётов), стоит держать ближе к
−35, а не к серединным значениям: замер сделан ровно на металлурге-экспортёре.

**Confidence levels:**
- `HIGH` — хорошо задокументировано в литературе, подтверждено несколькими кризисами
- `MEDIUM` — есть исторические данные, но нелинейно или режим-зависимо
- `LOW` — экспертная оценка, мало наблюдений или высокая неопределённость

**Источники калибровки:** кризисы 2008 (нефть -70%), 2014 (санкции, рубль -80%), 2020 (ковид, нефть -60%), 2022 (война, санкции, IMOEX -50% → частичный отскок). Данные MOEX section-returns, академические работы по российскому рынку (НИУ ВШЭ, ИЭПП).

**Важно: это исторические средние, не прецизионные оценки.** Диапазон в скобках отражает неопределённость.

**Тикеры:** SBER, SBERP, T, MBNK, BSPB, VTBR, RENI, SVCB

| Фактор | β | Диапазон | Confidence | Комментарий |
|--------|---|----------|------------|-------------|
| brent | +0.15 | +0.05…+0.25 | LOW | Косвенно через экономику; не прямая зависимость |
| usdrub | -0.10 | -0.20…+0.05 | LOW | Слабый рубль = инфляция → ставки выше → переоценка; неоднозначно |
| cnyrub | -0.05 | -0.15…+0.05 | LOW | Незначительный эффект |
| rate | **сложный** | см. ниже | MEDIUM | Нелинейная зависимость; см. примечание |
| sanctions | -35 | -55…-20 | HIGH | 2022: SBER потерял ~80% за пиковый период; SDN = катастрофа |
| geopol | -20 | -30…-10 | HIGH | Исторически банки реагируют сильнее индекса |

**Ставка — нелинейная зависимость:**
- Умеренный рост (+100–200 б.п.) при нормальной экономике: β = +0.10 (рост ЧПМ)
- Высокая ставка (>20%) с замедлением экономики: β = -0.30 (рост резервов, стагнация кредитования)
- Снижение ставки с нормального уровня: β = +0.20 (позитив для акций)
- Снижение ставки с экстремально высокого уровня: β = +0.35 (сильный позитив)

В матрице использовать контекст: `rate > 18%` → β = -0.30 за рост на 100 б.п.; β = +0.35 за снижение на 100 б.п.

## Нелинейности и взаимодействия факторов

### 1. Нефтяники: Brent + USD/RUB (компенсация)

В нормальных условиях нефть и рубль коррелируют: нефть вниз → рубль слабее. Это создаёт естественную хеджировку для нефтяников.

**Поправка:**
```
actual_effect = brent_effect + usdrub_effect × correlation_discount
correlation_discount = 0.35  # при режиме ЦБ 2022–2025 с капитальным контролем
```

Пример: Brent −20% (β=0.75 → −15%) + USD/RUB +15% (β=0.40 → +6%) → gross = −9%, но корреляция уже частично учтена в usdrub_effect → adjusted ≈ −11%.

**Когда поправка НЕ применяется:**
- Сценарий явно сочетает нефть вниз + рубль укрепляется (например, ЦБ-интервенции)
- Brent падает из-за спроса (рецессия), а не предложения

### 2. Банки: Ставка × Экономический контекст

| Контекст | Ставка растёт β | Ставка снижается β |
|----------|----------------|-------------------|
| Умеренная экономика | +0.10 (рост ЧПМ) | +0.20 |
| Ставка >18%, стресс экономики | -0.30 | +0.35 |
| Ставка >21%, кредитный кризис | -0.45 | +0.45 |

### 3. Комбинация: эскалация + нефть + рубль

Санкции и геополитика реализуются совместно (feedback loops), и это **закладывается
в β при её выборе**, а не применяется движком поверх:
- при сценарии с одновременной эскалацией обоих дилов — поднять |β_sanctions| и
  |β_geopol| позиции примерно на 30% против табличных
- нефтяники: дополнительно −5…−10 п.п. за страновой риск (через |β_geopol|)
- банки: −10…−15 п.п. за страновой риск (через |β_geopol|)

Поправка вносится в `betas-priors.json` осознанно, с отметкой в
`factor_betas_method`. Автоматического усиления в движке нет (см. §5).

### 4. Санкционный фактор — разные уровни внутри одной шкалы

Шкала интенсивности покрывает широкий спектр событий; калибровка β под конкретный:
- ~~**SDN конкретного эмитента** — β умножить на 2.0–3.0~~ — **правило замещено**
  калибровкой 2026-08-03. Класс «прямая блокировка бизнеса» (−35…−40) измерен
  ровно на SDN-эпизоде; множитель ×2–3 поверх дал бы −70…−120, далеко за
  измеренный диапазон. Вместо множителя — `sanctions_position` (насколько бумага
  уже прошла этот путь)
- **Секторальные санкции** — β как в матрице
- **Ужесточение price cap** — применять только к нефтегазу

---

### 5. Как санкционный и геополитический члены попадают в расчёт

Движок (`compute_per_position.py`) считает **чистую линейную свёртку** без
спецслучаев:

```
Δprice_pp = Σ_f  β_f × factor_f          # для всех 7 канонических факторов
```

Для политических факторов это `β_sanctions × intensity` и `β_geopol × intensity`,
где `intensity ∈ [-1..+1]`, **`+1` = ужесточение, `−1` = смягчение** (канонная
конвенция; все источники входа — macro-forecast-chain, scenario-builder, FCA —
обязаны её соблюдать). У чувствительных секторов β < 0, поэтому смягчение
(intensity < 0) даёт положительный вклад автоматически — отдельного правила знака
не требуется.

**Пример (банки, β_sanctions = −35):**

| Сценарий | intensity | Формула | Вклад |
|---|---|---|---|
| Статус-кво | 0 | `−35 × 0` | **0 п.п.** |
| Постепенное осложнение | +0.20 | `−35 × 0.20` | **−7 п.п.** |
| Жёсткий новый пакет | +0.70 | `−35 × 0.70` | **−24.5 п.п.** |
| Частичное смягчение | −0.30 | `−35 × (−0.30)` | **+10.5 п.п.** |
| Большая сделка | −0.90 | `−35 × (−0.90)` | **+31.5 п.п.** |

**Чего в движке НЕТ** (было описано в прежних редакциях этого файла, но никогда не
реализовывалось — не закладывайся):
- отдельного binary-члена `sanctions_escalation` со ступенькой `−0.5 × |β|` —
  удалено, движок этого никогда не считал;
- **автоматического** усиления обоих членов на 30% при совместной реализации.
  Ручная поправка допустима и описана в §3 «Комбинация» — но вносится в
  `betas-priors.json` осознанно, с отметкой в `factor_betas_method`, а не
  применяется движком поверх;
- нелинейностей §1–§3 (корреляционная поправка нефтяников, контекст ставки,
  страновой риск-премиум) — они **закладываются в саму β** при её выборе, а не
  применяются движком поверх.

Всё, что нельзя выразить бетой, — это либо интенсивность на стороне сценария,
либо `caveats` в итоговом YAML.

### 6. Горизонтный путь политических дилов

Интенсивность задаётся **на каждый горизонт**, а не одним числом на все:

```yaml
sanctions: {h6: -0.3, h12: -0.6, h24: -0.9}    # разрядка углубляется со временем
```

Один скаляр на все горизонты означает «разрядка через полгода = разрядка через два
года» и почти всегда неверен: `compute_horizon_factors.py` копирует такое значение
во все `hNN` и выдаёт warning (P0-2), а `compute_per_position.py` предупреждает,
если в `factors_by_horizon` политический дил одинаков на всех горизонтах.
Допустимо задавать путь и через уровни года: `{level_l1_2027: -0.3,
level_l1_2028: -0.9, unit: intensity}`. Смешивать две формы для одного фактора
**нельзя** — `compute_horizon_factors.py` откажется считать: какой источник главнее
для горизонта, который путь не покрывает, — вопрос без правильного ответа.

Горизонт, которого в пути нет, но который лежит **между** заданными точками,
получает линейную интерполяцию (при пути `{h6, h24}` запрошенный h12 — среднее, а
не значение h6); за пределами пути — плоская экстраполяция от крайней точки. Оба
случая помечаются warning'ом.

Величина β при этом **не** зависит от горизонта — от горизонта зависит только
интенсивность (D4-2).

## Использование матрицы при расчёте

### Базовый расчёт (линейный)
```
Δprice_pct = sum(β_factor × factor_change)
             для всех факторов в сценарии с ненулевым значением
```

### С поправкой на нелинейности
```
# 1. Рассчитать каждый factor effect отдельно
oil_effect = β_brent × brent_pct_change
fx_effect  = β_usdrub × usdrub_pct_change

# 2. Для нефтяников: применить корреляционную поправку
if sector == "oil&gas" and sign(oil_effect) != sign(fx_effect):
    # Нефть и рубль в противоположных направлениях — поправка не нужна
    pass
elif sector == "oil&gas" and oil_effect < 0 and fx_effect > 0:
    # Нефть вниз + рубль слабее (типичная корреляция) — натуральный хедж
    fx_effect_adjusted = fx_effect * (1 - 0.35)  # discount_factor
else:
    fx_effect_adjusted = fx_effect

# 3. Для банков: проверить контекст ставки
if sector == "banks":
    current_rate_context = determine_rate_context(current_cbr_rate, scenario_rate_change)
    β_rate = get_contextual_rate_beta(current_rate_context)

# 4. Суммировать
Δprice_pct = oil_effect + fx_effect_adjusted + other_effects
```

### Confidence для итоговой оценки
- Все β HIGH → итоговый confidence = HIGH
- Хотя бы один β LOW → итоговый confidence = LOW
- Остальные → MEDIUM

Помечать LOW-confidence оценки `⚠️` в выходной таблице.
