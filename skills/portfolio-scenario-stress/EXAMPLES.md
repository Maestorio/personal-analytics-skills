# EXAMPLES.md — Примеры использования portfolio-scenario-stress

Все примеры предполагают, что снапшот `PORTFOLIO-*.json` уже есть в `Portfolio-Snapshots/` (создан `portfolio-data-loader`). Прогнозный вход варьируется.

---

## Пример 1: Стресс-тест сразу после scenario-builder (один тред)

**Контекст:** в том же разговоре только что получил 4 Shell-сценария по теме «нефть и ставка ЦБ».

**Запрос:**
```
Запусти стресс-тест портфеля на этих сценариях.
```

**Что происходит:**
- Скилл видит 4 Shell-сценария в контексте разговора → использует только их (Тип A)
- Снапшот берёт автоматически из `Portfolio-Snapshots/`
- Веса равные (0.25 × 4); в выходе явная пометка: «equal-weighted, не вероятностно-взвешенный»
- Считает ΔP&L по 4 мирам, показывает концентрацию на нефтяном факторе

**Ожидаемый выход:** таблица 40+ позиций × 4 сценария, Top-5 уязвимых (вероятно нефтяники + длинные ОФЗ), hedge-кандидаты (ритейл, короткие ОФЗ).

## Пример 2: Точечная оценка перед заседанием ЦБ (через stress-tested forecast)

**Контекст:** ЦБ решает через 3 дня. Уже есть stress-tested прогноз по ставке от hypothesis-stress-tester: cut 100bp (P=0.60), hold (P=0.25), hike 50bp (P=0.15).

**Запрос:**
```
Применй этот stress-tested прогноз по ставке ЦБ к портфелю — хочу понять tail risk перед заседанием.
```

**Что происходит:**
- Скилл получает Тип C на входе → реальные вероятности, weight_type=probability
- Для облигаций: основной расчёт через дюрацию × Δставки
- Для банков: контекстный β (ставка >18% → асимметричные коэффициенты)
- Считает Expected P&L и P5/P95

**Ожидаемый выход:** Expected P&L = −2.1%, но в 15%-tail (hike scenario): −7.3% за счёт переоценки длинных ОФЗ (duration 8+ лет). Vulnerability map: SU26243, SU26238 — главные уязвимые; SBER — умеренно позитивен при cut, но хуже в hike.

## Пример 3: Авто-discovery — квартальный обзор без явных входов

**Контекст:** начинаешь новый разговор, хочешь периодический стресс-тест, прогнозов в чате нет.

**Запрос:**
```
Запусти стресс-тест портфеля.
```

**Что происходит:**
- Прогнозного входа нет → авто-discovery
- Скилл читает `Scenarios/*.yaml` и `forecasts/*.yaml` из Claude-Memory
- Находит: (a) stress-tested прогноз ставки от 2026-05-01, (b) Shell-сценарии нефть/рубль от 2026-04-15, (c) прогноз по геополитике «Иран-Израиль» от 2026-03-10
- Отсекает (c) — слишком транзитивен; для портфельного стресс-теста есть более проксимальные факторы
- Предлагает: «Использую (a) как основной вход по ставке, (b) как гибридное дополнение по нефти и рублю. Продолжить?»
- После подтверждения → расчёт

**Ожидаемый выход:** гибрид Тип C (ставка) + Тип A (нефть/рубль). Expected P&L по ставочной части — вероятностный; по нефтяной — equal-weighted. В confidence note явно указано, какая часть каким методом посчитана.

## Пример 4: Оценка новой позиции до покупки (ручной ввод)

**Контекст:** думаешь докупить TATN на ИИС-3. Хочешь понять, не усиливает ли это концентрацию на нефтяном факторе.

**Запрос:**
```
Предположим нефть упадёт до $55 (сейчас $85), ставка останется 21%, рубль 95. Как изменится портфель? И отдельно — покажи, что изменится, если добавить TATN на 100k ₽.
```

**Что происходит:**
- Ручной ввод (Тип manual) → `source: "manual"`, weight_type=equal (один сценарий)
- Первый расчёт: текущий портфель при нефть $55 (-35%), ставка без изменений, USD/RUB ≈ +5%
- Второй расчёт: портфель + гипотетическая позиция TATN 100k

**Ожидаемый выход:** сравнение concentration ratio «до» и «после» TATN. Если oil&gas уже 38% портфеля, добавление TATN поднимает до 44% — скилл покажет это явно. Не «не покупай», а «вот что меняется в distribution P&L».

## Пример 5: Эскалация — быстрый ответ на новость

**Контекст:** вышла новость о новом санкционном пакете. Нужно за 5 минут понять, где дыра.

**Запрос:**
```
Новые санкции — secondary sanctions на банки. Что теряю?
```

**Что происходит:**
- Скилл конвертирует описание в manual-сценарий: оценивает **интенсивность** пакета по шкале `[-1..+1]` (например `sanctions: {h6: 0.5, h12: 0.5}` — заметный, но не максимальный из мыслимых), остальные факторы не указаны → β не применяется
- Расчёт по `sanctions` и `geopol` (implied, если эскалация политическая)
- Быстрый фокус: банки (SDN-риск: SBER, T) и FLOT как наиболее уязвимые к secondary sanctions

**Ожидаемый выход:** таблица без незатронутых секторов — только те, у кого β к sanctions ненулевой. Top-5 уязвимых быстро. Confidence LOW для многих позиций (оценка интенсивности субъективна, разброс в реализации велик).

## Пример 6: Прогноз и сценарии существуют — выбор между ними

**Контекст:** в Claude-Memory есть stress-tested прогноз по нефти (Brent $65–75 при P=0.7, downside $50 при P=0.15) и Shell-сценарии по нефти/ставке от прошлого месяца.

**Запрос:**
```
Стресс-тест портфеля — сам найди что нужно.
```

**Что происходит:**
- Авто-discovery находит оба файла с пересекающимся нефтяным фактором
- Применяет правило: прогноз (Тип C) > сценарий (Тип A) при пересечении факторов
- НО: Shell-сценарии дополнительно содержат ставку и рубль, которых нет в нефтяном прогнозе → гибрид: Тип C для brent, Тип A для rate и usdrub
- Сообщает об этом до расчёта и ждёт подтверждения

**Ожидаемый выход:** nефтяная часть — probability-weighted (P=0.70/0.15/0.15); ставка и рубль — equal-weighted из Shell. В confidence note: «Нефтяной фактор: probability-weighted (stress-tested forecast). Ставка и рубль: equal-weighted (Shell-сценарии 2026-04-15). Смешанный тип весов — не суммировать в единый Expected P&L.»

## Антипаттерны — что скилл не делает

| Запрос | Почему не здесь |
|--------|----------------|
| «Что мне докупить с учётом этих сценариев?» | → ru-portfolio-advisor |
| «Построй сценарии по нефти» | → scenario-builder |
| «Пересчитай мой XIRR» | → portfolio-data-loader |
| «Взвесь прогнозы аналитиков по нефти» | → forecast-confidence-applier |
| «Проверь, устойчив ли этот прогноз» | → hypothesis-stress-tester |
