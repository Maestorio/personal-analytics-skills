# Источники консенсуса по доменам

Активируй релевантный набор по доменам тезиса (можно несколько одновременно). При сборе консенсуса на Шаге 3 нужно 2–3 первоисточника на каждый тезис, обязательно с датой публикации в окне ±1–2 недели от даты прогноза.

### Prediction markets (implied probabilities)

- **PredictIt** — академически признанный источник, ограничения по объёму
- Используй implied probability на дату прогноза, не на сегодня

### Консенсус-опросы аналитиков

## Принципы работы со списками источников

- **Для одного тезиса — минимум 2–3 источника**, разнесённые по типу (например: 1 sell-side + 1 prediction market + 1 think tank). Один источник = риск систематического искажения.
- **Дата публикации источника обязательна.** Если на дату прогноза источник ещё не вышел — он не учитывается, даже если по теме.
- **Архивные версии.** Для проверки on-date консенсуса используй archive.org Wayback Machine, если оригинальная страница изменена.
- **Платные источники.** Bloomberg Terminal, FactSet, Reuters Eikon недоступны напрямую через web search — но их данные часто пересказываются в публичных СМИ. Цитируй пересказ с явной пометкой «согласно [СМИ], данные [Bloomberg/Reuters]».
- **Отсутствие источника ≠ split consensus.** Если по теме просто никто крупный не высказывался — это «off-market», а не split. Split — когда есть явные противоположные позиции у институциональных игроков.
