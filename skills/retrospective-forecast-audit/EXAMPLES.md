# EXAMPLES: примеры работы скилла retrospective-forecast-audit

Учебный файл для скилла. Все примеры — из реальных аудитов (анонимизированных или с публичными авторами). Файл не содержит новой логики — только иллюстрации правил из `SKILL.md` и `references/domain-*.md`.

**Основной источник примеров в v1.0**: аудит вебинара Invest Era (А. Николаев) от 12.03.2025 по состоянию на 24.04.2026 (47 тезисов, hit rate 48,8%, альфа-генерация по Contrarian 66,7%).

---

## Раздел 1: Примеры запуска скилла

### 1.1 ✅ Срабатывает — запускает полный 7-шаговый аудит

**Финансы / sell-side, расшифровка прикреплена:**
> «Вот расшифровка вебинара Invest Era от 12 марта 2025 — оцени, насколько прогнозы сбылись»
→ Дата прогноза из документа (12.03.2025), дата оценки = сегодня. Активируется finance-ru consensus set + читается `references/domain-finance-ru.md`.

**Финансы / sell-side, именованный отчёт:**
> «Как сбылась годовая стратегия SberCIB на 2024 год?»
→ Уточнить: «Речь об outlook от декабря 2023? Или о промежуточных обновлениях?» → после ответа — аудит.

**Геополитика / think tank:**
> «Оцени прогнозы CFR по Украине из их отчёта января 2024»
→ Активируется геополитический consensus set (Polymarket, Metaculus, Brookings, Chatham House).

**Tech-CEO:**
> «Что предсказывал Альтман в интервью на Davos 2024 по поводу AGI — сбылось?»
→ Активируется tech consensus set (Gartner, IDC, Stanford AI Index, Metaculus).

**Telegram-канал / архив прикреплён:**
> «Насколько точен канал [название] за 2024 год? Прикладываю архив постов»
→ Дата прогнозов = диапазон из архива. Тезисы сортируются по дате внутри диапазона.

**Экономические последствия / регуляторика:**
> «Какие прогнозы делали по последствиям введения санкций на НКЦ в 2024? Насколько они оправдались?»
→ Активируется consensus set по регуляторике + глобальный макро.

**Явный запрос документа:**
> «Проверь прогнозы БКС за Q1 2025 и сделай документ с цветовым отображением»
→ Запускает аудит + создаёт docx с цветной таблицей вердиктов.

### 1.2 ❌ Не срабатывает

**Текущий прогноз без проверки постфактум:**
> «Что сейчас аналитики думают про ставку ЦБ?»
→ Нет прогнозной компоненты для проверки. Отвечаем напрямую без запуска методологии.

**Fact-checking без временного горизонта:**
> «Правда ли, что Сбер заработал 1,5 трлн в 2024?»
→ Разовая фактическая проверка, не аудит прогноза.

**Просьба сделать прогноз:**
> «Спрогнозируй курс рубля на конец 2025»
→ Не запускать. Это запрос генерации прогноза, а не его оценки.

**Оценка аргументации без временного горизонта:**
> «Оцени логику этой статьи о рисках рецессии»
→ Нет прогнозной компоненты с верифицируемым исходом.

### 1.3 ⚠️ Пограничные случаи

**Горизонт не наступил:**
> «Оцени прогнозы Маска из интервью февраля 2026 по AGI к 2030»
→ Ответить: «Горизонт прогнозов (2030) ещё не наступил — аудит преждевременен. Готов вернуться к оценке после [дата] или оценить частично те тезисы, у которых горизонт истёк».

**Смешанный материал (часть тезисов истекла, часть нет):**
> «Оцени годовую стратегию JPMorgan на 2025–2026»
→ Запустить аудит. Тезисы с горизонтом до сегодня — оценить, остальные — ⏳.

**Нет явной даты в материале:**
> «Вот статья — насколько сбылись прогнозы?»
→ Уточнить: «Дата публикации статьи и дата, на которую оценивать — не указаны. Уточни, пожалуйста».

### 1.4 🔁 После завершения аудита (дополнительные режимы)

**Сохранить профиль источника в память:**
> «Сохрани в память»
→ Режим A: генерирует compact-запись ≤500 символов, показывает пользователю, ждёт подтверждения, затем `memory_user_edits add`.

**Экспорт для другого скилла:**
> «Сделай выжимку для моего портфельного скилла»
→ Режим B: генерирует Markdown-блок с профилем источника, метриками и рекомендациями — готов для вставки в SKILL.md.

**Оба варианта:**
> «Сохрани в память и сделай выжимку»
→ Режим A → подтверждение → сохранение → Режим B.

## Раздел 2: Примеры декомпозиции A/B/C (Шаг 2 SKILL.md)

### 2.1 Простой монослойный тезис

**Цитата**: «Повышение ставки ЦБ выше 21% не произойдёт» (Invest Era, 12.03.2025)

| Слой | Содержание |
|---|---|
| A (предпосылка) | — |
| B (каузальность) | — |
| C (калибровка) | верхняя граница ставки в 2025 = 21% |

Тезис не требует декомпозиции: это прямое предсказание численного уровня. Проверяется одним фактом (факт: ставка достигла потолка 21%, пробоя не было → +2 L0).

### 2.2 Двухслойный тезис (A + C)

**Цитата**: «Снижение ставки произойдёт летом. В июне самый раз можно символически снизить» (Invest Era, 12.03.2025)

| Слой | Содержание | Условная вероятность |
|---|---|---|
| A | Цикл снижения ЦБ запустится в 2025 | высокая (консенсус) |
| C | Время: июнь 2025 | специфическое попадание |

Факт: 06.06.2025 ЦБ снизил ставку с 21% до 20% — первое снижение за 3 года, точно в июне. **Оба слоя L0, ценность +1** (Consensus + точная калибровка).

### 2.3 Композитный тезис с P-chain (A + B + C)

**Цитата**: «Новатэк — реальный бенефициар снятия санкций. В Корее лежат два танкера для Arctic LNG-2, если их разблокируют — это серьёзный буст» (Invest Era, 12.03.2025, парафраз)

| Слой | Содержание | P (на дату прогноза) |
|---|---|---|
| A | Мирные переговоры дают результат в 2025 | 0,30–0,50 (GS bond pricing 70%, но Russia-watchers ≤30% — split consensus) |
| B \| A | Санкции снимаются + специфически с Новатэка (а не только с Аэрофлота/Совкомфлота) | ~0,40 (не автоматично даже при B — NVTK не первый кандидат) |
| C \| B | Корейские танкеры разблокируются (отдельное технологическое/политическое решение Кореи) | ~0,30 |
| **Совокупная** | | **≈ 0,036 (3,6%)** |

Автор транслировал этот сценарий как «хорошие шансы» → в коммуникации звучит как P ≈ 0,5–0,7 → overclaim на 15+ п.п. Фактически A не реализовалось, санкции с NVTK не сняты, танкеры остались блокированы.

**Итог**: ценность −1 (L-B, частично реабилитировано тем, что цена NVTK выросла на общих ожиданиях до 1313 ₽ к апрелю 2026, но не по причине автора).

## Раздел 4: Примеры шкалы 2 (позиция к консенсусу) и snapshot sell-side

### 4.1 Consensus — совпадает с мейнстримом

**Тезис**: «Вероятность приостановки СВО выше 50%»

**Snapshot на дату прогноза (12.03.2025)**:
- Goldman Sachs: ~70% (bond pricing + betting markets)
- Polymarket: ceasefire by end of 2025 ≈ 55%
- Bloomberg survey: большинство аналитиков ждали «что-то» к лету 2025

→ Ставка автора (>50%) совпадает с рыночным консенсусом. Метка **Consensus**. При L-A это **мировая ошибка (🌍)**, снимается с автора.

### 4.2 Contrarian — явно против консенсуса

**Тезис**: «Нижняя граница $70 по Brent будет пробита вниз. Базовый сценарий — уход в нижнюю часть диапазона»

**Snapshot sell-side на март 2025**:
- Bloomberg consensus: $75–80 по году
- EIA STEO: ~$74
- IEA: $73
- БКС: $70 средний по году (нижний край)
- Goldman Sachs: $76

→ Автор явно ниже консенсуса. Метка **Contrarian**. Факт (Brent пробил $60 уже 09.04.2025, минимум $58,40) → L0 → **альфа (⭐), ценность +3**. Лучший тезис вебинара.

### 4.3 Off-market — тезис вне зоны обсуждения

**Тезис**: «При окончании СВО рынок вообще не будет покупать IT, это будет непопулярный сектор»

→ Этот тезис никто из sell-side явно не обсуждал. Метка **Off-market**. Факт: IT-сектор РФ — среди аутсайдеров 2025 (Диасофт, Позитив, Астра: −40…−60%) → L0 → ценность +2.

### 4.4 Split consensus — нет доминирующей позиции

**Тезис**: «Перемирие выиграет больше ВТБ, нежели МТС-банк»

**Snapshot sell-side март 2025**:
- БКС: VTBR HOLD/SELL
- Альфа-Инв: VTBR HOLD
- SberCIB: VTBR SELL
- Т-Инв: VTBR HOLD
→ По ВТБ sell-side был расколот (40/60 в пользу негатива).

Метка **Split**. Факт: ВТБ попал в топ-10 по доходности 2025 благодаря дивидендному сюрпризу, но параллельно провёл разводняющее SPO → смешанный результат → ценность +1.

### 4.5 Полный snapshot sell-side (образец)

Для каждой акции в аудите строится такая таблица. Пример по PLZL:

| Дом | Рекомендация (март 2025) | Target price | Invest Era |
|---|---|---|---|
| БКС | BUY | 1800 ₽ | **SELL (спекулятивно)** |
| Альфа-Инв | BUY | — | |
| SberCIB | BUY | — | |
| Т-Инвестиции | BUY | 2500+ | |
| Атон | BUY | — | |
| Финам | BUY | — | |

→ **5 из 5 домов BUY**, Invest Era — единственный SELL. **Истинная Contrarian-позиция.**

Факт: PLZL +55% в 2025, исторический максимум 2240 ₽ → ценность **−3 (сольный промах, 👤)**.

**Методологическое замечание** для РФ-рынка: baseline sell-side ~60% BUY. Поэтому «все дома BUY» не означает автоматически, что автор — Contrarian, когда повторяет BUY. Настоящий Contrarian — только когда идёт **против** всех (как Invest Era по PLZL, HNFG, GAZP). См. `references/domain-finance-ru.md` §2.

## Раздел 5: Примеры шкалы 3 (локализация ошибки)

### 5.1 L0 — нет ошибки

**Тезис**: «Повышение ставки выше 21% не произойдёт»
- A: потолок цикла повышения на 21%
- Факт: пик 21% удержан весь 2025
- → **L0**, ценность +1

### 5.2 L-A — ошибка в предпосылке

**Тезис**: «Аэрофлот — очень высокая вероятность снятия санкций»
- A (предпосылка): санкции с Аэрофлота будут сняты в 2025
- Факт: санкции не сняты. РФ предлагала снять 11.04.2025, США не ответили.
- → **L-A**. Ни B (бумага выиграет), ни C (насколько вырастет) не проверяются — предпосылка не активировалась
- Метка Consensus (большинство sell-side тоже ждали снятия) → **мировая ошибка 🌍** → ценность 0

### 5.3 L-B — ошибка в каузальной модели

**Тезис**: «Полюс — золото в вершине цикла, производитель не повторит результат 2024 года»
- A: золото достигло пика цикла (в моменте $2900/унц в марте 2025)
- B: производитель не может повторить результат при «остывании» золота
- Факт: золото продолжило рост ($3327/унц к апр 2025, >$4000 к окт 2025), PLZL +55%
- → **L-B**. Каузальная модель «вершина цикла → слабый производитель» опровергнута. Автор неправильно диагностировал стадию цикла + игнорировал структурные факторы (см. §6.2)
- Метка Contrarian (все sell-side BUY, Invest Era один SELL) → **сольный промах 👤** → ценность −2

### 5.4 L-C — ошибка в численной калибровке

**Тезис**: «До нижней границы 8,4% инфляция пойдёт»
- A+B: инфляция начнёт замедляться с апреля 2025
- C (калибровка): целевая граница 8,4%
- Факт: инфляция упала до 5,59% — быстрее и сильнее
- → **L-C**. A и B верны, численная цель промахнулась в безопасную сторону
- Метка Consensus → ценность −1

### 5.5 L-R — дополнительный штраф за пропущенный хвостовой риск

**Тезисы**: «Новатэк/Совкомфлот/Аэрофлот — реальные бенефициары снятия санкций»
- Основная локализация: L-A (санкции не сняты)
- Дополнительный штраф L-R: автор **не обсудил** риск **новых** санкций США. Факт: 22.10.2025 Трамп ввёл санкции против Роснефти и Лукойла. Это материальный хвостовой риск, который реализовался и ударил по всему нефтегазовому сектору
- L-R помечается ⚠️, добавляет −1 к базовой ценности
- Для NVTK/FLOT/AFLT: базовая ценность −1 (L-A Consensus) + L-R −1 = **итого −2**

## Раздел 6: Shape-of-error блоки (для ошибок ≤ −2)

### 6.1 Shape-of-error: T25 PLZL «золото в вершине цикла» (ценность −2)

**Ложная предпосылка в модели автора:**
«Золото достигло вершины долгосрочного цикла (~$2900/унц) → производитель не может повторить результат 2024 года»

**Игнорируемые факторы (доступные на дату прогноза):**
1. **Структурный bid от ЦБ развивающихся стран**: World Gold Council уже публиковал данные за 2024 о рекордных покупках ЦБ (~1045 тонн/год, третий год подряд >1000 т). Это структурный фактор, не циклический.
2. **Дедолларизация резервов после 2022**: тренд начался с замораживания ЗВР РФ, ускорился в 2023–2024. Выход из долларовых/евровых активов → золото.
3. **Пространственный запас тренда в реальных ценах**: исторический пик 1980 года ($850/унц) в ценах 2025 ≈ $3100/унц. То есть $2900 в марте 2025 **не был** реальным пиком. Автор сравнивал номинальные цены.
4. **Геополитическая премия**: СВО + возможные шоки на Ближнем Востоке (реализовались 28.02.2026 — удары по Ирану).

**Паттерн у автора** (кластер ошибок в одном стиле мышления):
Идентификация стадии цикла через номинальную ценовую метрику без учёта структурных драйверов. Аналогичный паттерн в T20 «разрыв IMOEX с денежной массой сократится» — та же логика «возврат к среднему» без учёта смены режима (санкции, высокая ставка как структурный фактор).

**Стоимость ошибки для подписчика:**
- Рекомендация «спекулятивно смысла нет» при цене ~15 000 ₽ (до сплита) на март 2025
- PLZL дошёл до 67 200 ₽ (до сплита) к апрелю 2026 → +55%
- Упущенная выгода на позиции: >50% годовых
- Плюс 3 купона дивидендов: 73 + 70,85 + 36 ₽ на акцию (после сплита)

### 6.2 Shape-of-error: T1 + T4 + T22 «симметричный deal» (кластер)

**Общая ложная предпосылка в модели автора:**
«Переговоры США–РФ идут к симметричной сделке, где взаимно снимаются санкции и возвращаются активы»

**Игнорируемые факторы:**
1. **Параллельный экспертный consensus GS** от 13.03.2025 (день вебинара): «No, quick end is not probable» (Russia-watchers) — автор опирался на bond-pricing GS (70%), но не на экспертную часть того же выпуска
2. **Асимметрия в требовании снятия санкций**: РФ публично предлагала снять санкции с Аэрофлота 11.04.2025 — США не ответили. Это факт, доступный в реальном времени
3. **Институциональная инерция США**: OFAC требует длительных процедур для разморозки активов, даже при политической воле

**Пропущенный хвостовой риск (L-R):**
Новые санкции США против Роснефти и Лукойла 22.10.2025 — противоположное направление от «смягчения». Автор не упомянул этот сценарий в рисках.

**Паттерн**: модель «А → B → C» без проверки сценариев NOT-A, NOT-B. Автор рассматривал только успешную ветвь переговоров.

**Стоимость для подписчика:**
Портфель с перекосом в «бенефициаров санкционного смягчения» (NVTK, FLOT, AFLT, MOEX) за год показал −10…−30%, в то время как IMOEX упал на −10%. То есть тематическая ставка ухудшила портфель на 10+ п.п. относительно индекса.

## Раздел 7: Примеры маркеров в таблице вердиктов

| Тезис | Факт | vs sell-side | Локализация | Маркер | Ценность |

2. **Идентификация стадии цикла через номинальные цены** (без поправки на CPI и структурные драйверы)
3. **«Готов держать до цели» без stop-loss**: T21 (4000 IMOEX) — нет правил выхода при реализации медвежьего сценария
