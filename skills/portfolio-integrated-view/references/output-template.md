## 📖 §8. Глоссарий {#glossary}

*(Дублирует шапку для быстрого поиска.)*

- **Макро-вклад** — ожидаемое изменение цены из стресс-теста, взвешенное по нормированным вероятностям сценариев.
- **Дивиденды** — div yield за 12 мес × 20/12.
- **Идиосинкр. α** — вклад катализаторов эмитента. Дисконт 0.7: катализаторы без макро-зависимости несут исключительно эмитент-специфичный риск (один источник отказа). Дисконт 0.5: дополнительно при низком доверии к источнику прогноза. При наличии макро-зависимости используется `p_joint = p_scenario_norm × p_catalyst` без дополнительного дисконта.
- **CI консервативный** (corr = 1) — линейное сложение интервалов, верхняя граница неопределённости.
- **CI реалистичный** (corr = 0) — квадратурное сложение, нижняя граница. Реальный CI лежит между ними.
- **Нормировка сценариев** — применяется автоматически: `p_norm = p_i / Σ p_i`.
- **Sc-A/B/C/D** — четыре сценария стресс-теста, расшифровка в `stress-{date}.yaml`.
- **Решение BUY/HOLD/SELL** — рекомендация еженедельного обзора, **не вывод этого синтезатора**.
- ❄ = ИИС-3.
