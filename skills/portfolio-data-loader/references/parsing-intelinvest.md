# Парсинг trades_portfolio_*.xlsx (IntelInvest)

Этот файл — полная история сделок портфеля. Типичный размер: ~9000 строк.
Парсится через `scripts/portfolio_returns.py` с `openpyxl`.

---

## Структура файла

IntelInvest экспортирует сделки **парными записями** для каждой транзакции:

```
Строка A: операция по ценной бумаге (qty, цена, тикер)
Строка B: операция по деньгам (сумма в рублях/валюте, комиссия)
```

Обе строки связаны одной датой и `trade_id`. Скрипт читает пары, не одиночные строки.

**Ключевые колонки:**
- `Date` — дата операции
- `Ticker` / `Name` — идентификатор бумаги (тикер или ISIN или название)
- `Operation` — тип операции (см. ниже)
- `Qty` — количество (положительное = покупка, отрицательное = продажа)
- `Price` — цена одной единицы
- `Amount` — сумма в валюте операции
- `Currency` — валюта (`RUB`, `USD`, `EUR`, `CNY`)
- `Fee` — комиссия брокера

---

## Типы операций

| Operation | Описание | Обработка |
|-----------|----------|-----------|
| `Покупка` | Купил бумагу | qty+, cash− |
| `Продажа` | Продал бумагу | qty−, cash+ |
| `Дивиденды` | Выплата дивидендов | cash+ (классификация = stock) |
| `Купон` | Выплата купона | cash+ (классификация = bond) |
| `Амортизация` | Амортизация номинала | qty неизменен, cash+ |
| `Корректировка` | Синхронизация остатков | По знаку amount (см. splits-corrections.md) |
| `Пополнение` | Взнос на счёт | Внешний cashflow |
| `Вывод` | Вывод со счёта | Внешний cashflow |
| `Обмен валюты` | RUB↔USD/EUR/CNY | Парная запись, исключается из инварианта |

## TMF Forced Close

IntelInvest не зафиксировал все записи по TMF (заблокированный ETF).
`portfolio_returns.py` создаёт виртуальную продажу остатка TMF на дату `05.08.2024`
с нулевой ценой — чтобы закрыть позицию корректно.

Отражается в `corrections_log`: `type: "tmf_forced_close"`.

## Заблокированные позиции — классификация

`portfolio_returns.py` автоматически классифицирует бумаги как заблокированные:

1. **По префиксу:** FinEx (`FXGD`, `FXRU`, `FXMM`, `FX*`), Rosbank (`RSH*`)
2. **Явный whitelist заблокированных:** TMF, TBIO, GOLD, TLT, SPXU, SDS, SH, VIXY
3. **По точке в тикере:** `EOAN.DE`, `SIEGY` — иностранные
4. **По отсутствию активности после 01.03.2022:** иностранные акции без операций

**Whitelist российских фондов** (НЕ блокировать):
`TPAY, TGLD, LQDT, TLCB, SBMX, EQMX, AKMB, OBLG` и другие БПИФ на российских площадках.

**Default оценка заблокированных:** 0 ₽ (реалистичный пессимистичный сценарий).
Альтернатива через `--blocked-value last_trade` — для совместимости с IntelInvest.

## Замещайки (FX-облигации) — особый случай

Замещайки (заместившие еврооблигации) торгуются на MOEX в рублях, но их **номинал** в USD/EUR/CNY.

IntelInvest хранит валюту сделок как `RUB`, но реальная экспозиция — в иностранной валюте.

`portfolio_returns.py` определяет `nominal_currency` через:
1. MOEX ISS → `FACEUNIT` поле (приоритет)
2. `KNOWN_FX_BONDS` реестр — 16 известных замещаек пользователя (fallback)

При пересчёте стоимости в рубли используется курс ЦБ РФ для `nominal_currency`, не `RUB`.
Поле `price_source` помечается `+fx_registry` если использован fallback-реестр.

## Кэш курсов ЦБ РФ

Для RUB-конвертации сделок в USD/EUR/CNY используются курсы ЦБ РФ на дату сделки.

**Bundled cache:** `scripts/references/cbr_rates_bundled.json`
- Покрытие: USD/EUR/CNY, 2019 → дата релиза скилла (~4800 точек, 104 КБ)
- При старте `load_cbr_cache()` подмешивает bundled в рабочий `/tmp/cbr_rates_cache.json`

**Fallback при 503 от ЦБ:**
- Не очищать кэш, не перезапускать
- Скрипт делает 4 попытки retry
- При полной недоступности: `--cbr-offline` (только bundled cache)
- Для прошлых дат bundled покрывает всё; для свежих дат — последнее известное значение

---

## Chunking и производительность

Первый запуск `portfolio_returns.py` загружает курсы ЦБ РФ для всех дат сделок:
- Может занять 10–30 секунд (HTTP-запросы к ЦБ, чанки по 364 дня)
- Кэш сохраняется в `/tmp/cbr_rates_cache.json`
- Последующие запуски в той же сессии — мгновенные

## Типичные ошибки парсинга

| Симптом | Вероятная причина | Действие |
|---------|------------------|----------|
| qty аномально маленький (в 10× или 100×) | Новый сплит, не учтённый в KNOWN_SPLITS | Обновить реестр (splits-corrections.md) |
| XIRR `None` или бесконечность по тикеру | Только outflows или только inflows | Проверить cashflows: скорее всего закрытая позиция |
| Расхождение с IntelInvest > 0.25 п.п. | Double-apply сплитов или конвертаций | Сплиты применяет только reconstruct_positions (split_factor); проверить повторные вызовы merge_cross_currency |
| Внезапный большой "депозит" в cashflow | Неисключённая валютная конвертация | Проверить parse_fx_conversions() |
