# Consistency Rules — macro-forecast-chain

## Принципы

Consistency check — не блокировка, а информирование. Цель: убедиться,
что пользователь осознаёт нетипичные комбинации и принял их сознательно.

Серьёзность (severity):
- `critical` — экономически невозможная комбинация (логическое противоречие)
- `medium` — нетипично, но возможно при особых условиях (требует обоснования)
- `low` — необычно исторически, но не противоречит логике (информировать)

|---------|----------|-----------|
| brent_pct > +10% AND usdrub_pct > +5% | medium | «Нефть↑ + рубль↓ — нетипично. Обычно нефть↑ укрепляет рубль через нефтегазовые доходы. Возможная причина: санкционный разрыв или отток капитала» |

## Процедура при critical severity

При `critical` severity скилл:
1. Явно останавливается и выводит предупреждение
2. НЕ предлагает «принять как есть» — только пересмотреть
3. В Checkpoint 2 требует явного текстового объяснения (не просто [Y])
4. Записывает объяснение в caveat с пометкой `severity: critical`

## Суммарная оценка consistency

После проверки всех правил вывести итог:

```
Consistency Summary:
  Critical:  N (блокируют сборку без объяснения)
  Medium:    N (требуют подтверждения)
  Low:       N (информационные, в caveats)
  OK:        N

Матрица совместима: ДА / НЕТ (есть критичные без объяснения)
```
