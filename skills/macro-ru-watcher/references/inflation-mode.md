# Режим «Обнови инфляцию»

Короткий режим: одна запись недельной инфляции в `macro-snapshots/inflation/model.jsonl`. Страница «Макро» вьюера
берёт из двух файлов (этот и `owner.jsonl`, который пишет форма сайта) самую свежую запись по `date`.
Срок годности записи: старше 9 дней — жёлтая плашка, старше 16 — красная.

## Шаги

1. Транспорт — как в основном режиме (Synology mount); недоступен → остановиться и сообщить.
2. Найти **последнюю** недельную публикацию: Росстат («Информация о недельной динамике потребительских цен»,
   выходит по средам) или МЭР («О текущей ценовой ситуации»). Только страница из ТЕКУЩЕЙ сессии
   (web_search / web_fetch), не память. Не нашёл — остановиться: «недельной публикации не нашёл», ничего не писать.
3. Выписать из публикации:
   - `date` — дата публикации (ГГГГ-ММ-ДД);
   - `week_pct` — инфляция за неделю, %;
   - `week_period` — период недели текстом («03–09.11»);
   - `yoy_pct` — годовая инфляция на дату публикации, % (оценка по неделям; если в публикации её нет — взять из
     той же публикации МЭР, иначе остановиться);
   - `yoy_as_of` — дата, на которую оценка г/г;
   - `source_name` («Росстат» / «МЭР») и `source_url` — ссылка на страницу публикации.
4. Проверить запись без записи, затем записать:

```bash
python3 scripts/save_inflation.py --root "$CM" --date 2026-11-12 --week-pct 0.11 --week-period "03–09.11" \
    --yoy-pct 6.4 --yoy-as-of 2026-11-09 --source-name "Росстат" --source-url https://… [--apply]
```

   Код 1 — поле не прошло проверку (текст ошибки в stderr): поправить по публикации, не подгонять число.
   Код 3 — сайт в режиме «без ИИ»: ничего не писать, сказать владельцу, что инфляцию вносит форма на сайте.
   «уже записано» — та же публикация внесена ранее, повторять не нужно.
5. В чат — одна строка: `Инфляция внесена: неделя {period} {week_pct}% · г/г {yoy_pct}% на {yoy_as_of} · {source_name}`.
   Без интерпретаций и прогнозов (принципы 1 и 4 основного режима).
