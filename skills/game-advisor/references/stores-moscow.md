## Протокол ПРОВЕРКИ ЦЕН по магазинам

1. web_fetch каталожной страницы или поиска магазина по названию игры
   (у большинства поиск: `?q=<название>` или аналог — определить по факту).
2. Если fetch каталога не находит позицию — web_search `site-независимо`:
   `<магазин> <игра> купить` и fetch конкретной карточки.
3. Фиксировать: цена, наличие (в наличии/предзаказ/нет), формат (Switch 1 / Switch 2
   Edition / Key Card). **Switch 2 Game-Key Card ≠ полноценный картридж** — данные
   грузятся из сети, отмечать явно (важно для коллекции/перепродажи).
4. Цены только из fetched-страниц с датой проверки. Устаревшие кэши поисковиков
   не считаются источником.

## US eShop

- Основной прайс + скидки: https://www.dekudeals.com/ (агрегатор, история цен,
  алерты). Карточка: `dekudeals.com/items/<slug>`.
- Прямой источник: nintendo.com (US). Скидки Nintendo циклами (~2-4 недели);
  крупные сейлы: Blackriday/Cyber, декабрь, E3-период (июнь), Golden Week-адаптации.
- Сравнение цифра US vs физика Москва вести в рублях по текущему курсу USD/RUB
  (указывать курс и дату).
