# Trust tiers источников оценки игр

Согласовано с пользователем 2026-07. Формат аналогичен source trust library
финансово-геополитических скиллов. Пересматривать при CALIBRATE, если источник
систематически ведёт к промахам (miss в recommendations/*.md).

| Источник | Trust | Использование |
|---|---|---|
| HowLongToBeat (community) | HIGH | длительность (Main / Main+Extra / Comp), retirement rate |
| OpenCritic | HIGH | агрегированный critic score (без Metacritic weighted-магии) |
| Steam user reviews (>500 отзывов) | HIGH | для мультиплатформы — прокси качества порта смотреть отдельно |
| eShop user ratings | MEDIUM-HIGH | меньше объём, но платформо-специфичны |
| YouTube no-commentary gameplay / несп. letsplay | MEDIUM-HIGH | оценка actual feel, темпа, UI на handheld |
| Metacritic critic score | MEDIUM | известный inflation bias части изданий; юзать как второе мнение |
| Reddit r/NintendoSwitch2, r/patientgamers | MEDIUM | качественные сигналы, но селекция по хайпу |
| Digital Foundry | HIGH (только техчасть) | качество порта на Switch 2: fps, разрешение, загрузки |
| IGN / GameSpot / Kotaku обзоры | LOW | рекламная зависимость; только как источник фактов, не оценок |
| Маркетинг паблишера, трейлеры | IGNORE | факты о дате/цене — ок, оценочные суждения — нет |

## Правила применения

- Рекомендация должна опираться минимум на 2 источника trust ≥ MEDIUM.
- Расхождение критиков и юзеров > 15 пунктов (нормализованно) — флаг, разобрать причину
  (обычно: техсостояние порта, монетизация, ожидания фанбазы).
- Для портов на Switch 2 обязательна проверка качества порта (Digital Foundry
  или свежие user reviews именно Switch-версии) — оценка PC-версии непереносима.
- Ссылки на источники в выдаче обязательны (требование верификации первоисточников).
- **Техно-гейт (flag-but-show).** 30fps — не штраф. Красный флаг + понижение позиции в
  списке (но НЕ исключение) при: заметном дёрганье / плохом фрейм-пейсинге; явных
  претензиях Digital Foundry к техсостоянию порта; либо перф-жалобах в свежих отзывах
  именно Switch 2-версии (ориентир: перф-негатив в заметной доле отзывов). Решение о
  покупке остаётся за пользователем — гейт информирует, не запрещает.
