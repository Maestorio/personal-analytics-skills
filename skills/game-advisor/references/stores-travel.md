Сид для режима МАГАЗИНЫ В ПОЕЗДКЕ. Это точки, которые пользователь проверил лично
(покупал / был / подтвердил карточку). Список НЕ исчерпывающий и НЕ отменяет
протокол режима #5: при запросе по городу всё равно делать самостоятельный
web_search локальных точек и **перепроверять свежесть** (магазин мог закрыться,
адрес/график измениться — источник ≤ 6–12 мес). Здесь — только стартовые якоря.

Формат verified: дата последней проверки пользователем/скиллом.

### Дисциплина по этим точкам

- **Наличие Switch подтверждать точечно.** Приставкин — Switch-картриджи подтверждены
  вживую. GameBit — по ассортименту Авито (webarchive 2026-07-06) Switch/Switch 2
  картриджи есть, но уклон ретро (N64/Gamecube/Wii); наличие конкретной игры меняется —
  проверять запросом. Пользователь внутри магазина не был (выходные нерабочие).
- **Витрина без каталожной страницы (GameBit продаёт через Авито/мессенджеры)** — цены и
  наличие только по факту запроса; для точечной проверки — Авито-бренд или мессенджер.
  Есть Авито Доставка (можно заказать дистанционно, не только в поездке).
- **Прошитые/модинг-консоли (GameBit)** — вне интереса пользователя (легальный US-аккаунт,
  коллекция оригиналов); в рекомендации по покупке не выдвигать.
- **webarchive как источник** — снимок на дату; конкретные лоты Авито быстро уходят.
  Ассортимент/специализацию фиксировать можно, отдельные цены/лоты — как «на дату архива».
- **Region-lock:** картриджи Switch region-free (базовые игры на US-аккаунте — ок);
  обновления Switch 2 Edition и DLC привязаны к региону аккаунта покупки — предупреждать.
- При self-search новых точек в этих же городах — добавлять сюда через ОБНОВЛЕНИЕ (не
  затирать проверенные записи; новые помечать verified с датой).
