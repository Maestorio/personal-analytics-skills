# personal-analytics-skills

**EN.** A personal analytics workbench built as a set of Claude Code skills, deterministic Python scripts and a small web front-end. The main line is investment analytics for a Moscow Exchange portfolio; the same architecture is reused for personal finance, travel planning, recipes and health records.

**RU.** Личная аналитическая система: набор скиллов Claude Code, детерминированные Python-скрипты и веб-интерфейс. Основное направление — аналитика инвестиционного портфеля на Мосбирже; та же архитектура применена к личным финансам, планированию поездок, рецептам и здоровью.

## Принцип

```
данные (брокер, MOEX ISS, ЦБ) → детерминированные скрипты → ИИ-интерпретация → проверка контрактов → веб-интерфейс
```

Модель интерпретирует и формулирует. Расчёты, схемы данных и запись файлов — на стороне скриптов и валидаторов.
Каждый скилл ограничен контрактом (YAML/JSON-схемы, pre-emit чек-листы), а ответы модели проверяются кодом.

## Инвестиционный контур

- **Загрузка портфеля** → расчёт XIRR, TWR, ROI по позициям, сверка с балансом.
- **Прогнозы:** сбор, взвешенный консенсус с учётом доверия к источникам, ретроспективный аудит точности (исполнение / позиция к консенсусу / локализация ошибки).
- **Сценарии и стресс-тест:** матрица 2×2 из реальных разногласий → ΔP&L по каждой позиции.
- **Интегрированный вид:** read-only свод снапшота, стресса и обзоров с доверительными интервалами, без рекомендаций.
- **Мета-аудит:** поиск противоречий между артефактами и совместных хвостовых рисков.

## Данные и конфиденциальность

В репозитории нет реальных данных владельца: портфельные фикстуры обезличены (суммы и количества масштабированы),
имена и адреса заменены, конфиги хостинга даны только как `*.example`. Реальные данные живут вне репозитория.
Некоторые проверки, зависящие от личного хранилища, на чужой машине пропускаются.

Скрипты и страницы рассчитаны на конкретную инфраструктуру автора (NAS, Caddy, Synology Drive); для запуска у себя
адреса и пути нужно заменить на свои.

Это исследовательский проект. Он не является инвестиционной рекомендацией.
