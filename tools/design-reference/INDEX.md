## Важные оговорки
1. **`design_handoff_portfolio_viewer/viewer.css` в проекте — УСТАРЕВШИЙ** (это вход в
   прогон Claude Design, не результат: `.fpill`/`.decomp-bar`, без нового каталога).
   Реальная система — только в `.dc.html` `<style>` (= `design-tokens-extracted.css`).
2. **Шрифты и база**: в `.dc.html` — Google Fonts CDN. В проде — self-host
   (Golos Text + Spectral, кириллица, приватность/офлайн). С viewer 2.17.9 /
   ui-kit 1.6.0 `@font-face`, общие токены тем и базовый слой body живут в
   **`assets/ui-kit.css`** (единый файл базы для всего кабинета, вьюер подключает
   его ДО `viewer.css`); в `viewer.css` — только токены самого вьюера
   (`--accent-line`, `--diff-*`, `--c-equity`/`--c-bond`). Шрифт в правилах —
   только `var(--font-sans)`/`var(--font-serif)`. При порте из дизайна общие
   токены вносить в ui-kit.css, не в viewer.css.
3. **Больше вкладок, чем в дизайне**: реальный вьюер имеет вкладки сверх 14
   (напр. «Оговорки», «Что не показано»; в дизайне caveats свёрнут в «Интеграционный»).
   Всё, что выходит за рамки Claude Design, **сохраняем и подгоняем под стиль** — не
   выбрасываем и не оставляем без стиля.
4. **Имена классов/переменных — источник истины** (`.chip-toggle`, `.verdict-grid`,
   `.meter`, `.ret-stack`, `.stat-grid`, `.scn-block`, `.fc-card`, `.consensus` …).
   Логику/id/data-binding `viewer.js` не менять — только презентационную разметку.

## Статус реализации

**v3.0.0 (2026-10-12) — вьюер на общем ui-kit** (решения владельца — `docs/investment/TODO_design.md`
§1 «Решения сессии 2026-10-12», карта компонент — `viewer-ui-kit-map.md`). Разделы — одной строкой
`.ui-tabs` без эмодзи: Сегодня · Акции · Облигации · ИИС-3 · Выплаты · Динамика · Стресс · Действия ·
Изменения · Доли и цели · «Ещё ▾» (Интеграционный анализ · Прогнозы · Макро · Источники · Оговорки ·
Что не показано). Имя раздела `.ui-h1` + строка «данные на …»; главные числа — плитки
`.ui-grid.kpi`/`.ui-big` «как в Деньгах» с мини-графиком `.ui-spark.sm` за 6 мес по календарю;
карточка бумаги — окно `uiModalHTML` 1150px по центру (`tall`, стопкой), подвкладки `.ui-seg.sm.acc`,
листание ← → со сдвигом `uiAnimIn`. Chart.js — только «Стресс» и «Динамика» (было 6 мест):
распределения облигаций — полосами, график погашений → «Выплаты» (`.ui-cols.ro`), секторы IE —
сняты, «Макро» — `.ui-spark`. **v3.2.0 (2026-10-13)** — остаток: все карточки разделов — `.ui-card.lg`
+ `.ui-h2` (без эмодзи), плашки — `.ui-alert.tight`, мини-сводки — `.ui-stat`, таблицы «Акций»,
«Облигаций», стресса, вердиктов, предсказаний — `.ui-table.dense` (ui-kit 1.41.0) с `aria-sort` и
липкой шапкой; своих `section.card`/`.banner`/`.eyebrow`/`.stat-grid`/`table.compact` больше нет
(контракт). Свои правила вьюера (viewer.css) остались для доменного: фильтры-чипы таблиц, вердикт-теги, режим чтения отчётов (`renderReportDoc` — не трогали по
решению 2026-10-06), окно документа `#modal-overlay` (слой 300 — над карточкой).

**v2.5.0 — все 14 вкладок + 3 модалки на дизайн-системе** (single-file → multi-file
`HTML + assets/viewer.css + viewer.js`, self-host шрифты, палитра в токенах). §4-герой
Интеграционного собран как `verdict-grid` на **чистом CSS/`errbar` без Chart.js** —
рисуется детерминированно.

**v2.14.0 → v2.15.0 — режим чтения длинных отчётов** (`.report-doc` +
`.report-toc`/`.rp-bar`). Расширение сверх Claude Design: длинных markdown-документов
в референсе нет, а отчёты advisor'а, полные обзоры акций/облигаций и integrated-view —
это 10–40 КБ прозы. Грамматика прежняя (токены, Spectral/Golos, обе темы), новое —
только реализация чтения: серифный текст Spectral 17px/1.75 во всю ширину колонки
(~85–90 знаков), шкала 28/23/18.5 + Golos-подзаголовок на `h4`, TL;DR панелью,
оглавление из `##`/`###` самого документа — липкий столбец на десктопе и липкая
полоса со шторкой на телефоне (приём nav-layer travel-экспорта), выбор ранее
загруженной версии отчёта в шапке. Все три жанра идут через один `showDocModal`.

**v2.16.0** добавляет над документом карточку провенанса `.rp-meta` (тип/режим/модель/
горизонт и `related_artifacts` с отметкой «загружен ли файл в этой сессии»; у
integrated-view — входы с возрастом), а списку отчётов — поиск, фильтр по типу
чипами и аннотацию из `summary`.

Три решения, которые легко откатить по незнанию:
- **Мера строки — это ширина модалки (`max-width` у `.modal.modal-report`), а не
  обрезка абзаца.** Первый заход держал колонку в 70ch внутри 1160px-модалки, и
  треть ширины пустовала справа — читалось как поломка, а не как приём.
- **Разметка markdown — классы `md-*`, не инлайн-стили.** Инлайн бьёт класс по
  специфичности: один возвращённый `style=` молча отключает весь режим чтения.
- **Шапка отчёта — только из frontmatter.** У md-обзоров акций/облигаций его нет,
  и провенанс оттуда не выскребается: на скрейпе прозы уже горел §4-герой.

Обе стороны пришпилены `tools/tests/test_pages_contracts.py` (ось «класс в JS ↔
правило в CSS»).

### «Наверх», Escape и меню при открытых окнах (ui-kit 1.64.0)

- **Наверх — только `uiScrollTop(el?)`**: всегда мгновенно (без плавной прокрутки, независимо от
  `prefers-reduced-motion`); без аргумента — окно страницы, с аргументом — прокручиваемый контейнер
  (окно, читатель). Своих `scrollTo(0,0)` / `scrollTop = 0` «наверх» на страницах нет (внутренние
  механики сохранения и восстановления прокрутки — не в счёт). Плавно остаются только переходы по
  оглавлению к главе.
- **Меню, рельс и вкладки поднимают сами**: нажатие пункта `.ui-mnav` / `uiRailHTML` / `uiTabsMount`,
  в том числе текущего, вызывает `uiScrollTop()` после того, как страница перерисовала вкладку
  (rAF) — в обработчике страницы подъём не пишется. Действия не из меню (кнопка-ссылка на вкладку,
  смена фильтра) поднимают страницей через `uiScrollTop()`.
- **Escape и меню при открытых окнах — через `uiLayerBind`**: одна регистрация на страницу —
  `uiLayerBind({ depth: () => число открытых слоёв, closeTop: (ev) => закрыть верхний (false —
  «ничего не закрыл»), dirty: () => у открытого слоя несохранённые правки (`uiFormDirty(корень)`
  сравнивает поля с исходной разметкой), closeAll?: () => закрыть всё сразу })`. Собственные окна
  ui-kit (справка, список, всплывающее окно вкладок, подсказка (i), подтверждение, поиск) обрабатывают
  Escape первыми; иначе при `depth() > 0` ui-kit гасит событие (`preventDefault` — Mac не выходит из
  полноэкранного режима) и зовёт `closeTop`. Пункт меню/рельса/вкладки при открытых слоях: `dirty()` —
  `uiConfirm` «Закрыть без сохранения?» («Остаться» — ничего не происходит), затем все слои закрываются
  и выполняется переход с подъёмом. Своих `keydown` с Escape на странице нет — «что закрыть» живёт в
  `closeTop` (поля ввода, где Escape окно не закрывает, — `return false`).

### Окна стопкой с плавным переходом (ui-kit 1.33–1.36, образец — money «к прошлому году»)

Когда из окна открывается второе окно (детализация: «Обычные траты» → категория), второе
въезжает поверх, а первое уходит «назад» — сдвинуто, чуть меньше и приглушено, его край
виден; Esc/✕ закрывают по одному, нижнее плавно возвращается на место. Логика стопки — в
ui-kit (1.36.0), страница держит только состояние (массив окон) и рисует все окна сама:

1. Состояние — массив окон (`S.stack = [...]`) и `fresh` — индекс только что открытого окна
   (сбрасывать после перерисовки, иначе анимация повторится на каждом клике внутри окна).
   Рисовать все: `uiModalHTML({ …, z: 210 + i, cls: uiStackCls(i, n, fresh), bodyId: "…-" + i })`.
2. Закрытие (✕, затемнение, Esc — верхнее): `uiStackPop(document.querySelectorAll(".ui-modal"), i,
   function(){ /* убрать окна от i и выше, перерисовать */ })` — верхнее уходит, нижнее
   возвращается, повтор во время анимации и «уменьшить движение» ui-kit обрабатывает сам.
   Ставить `.leave`/`.return` страницей запрещено (контракт).
3. Прокрутка окон: до перерисовки `var keep = uiStackKeepScroll("…-", n)`, после — `keep()`.
4. Своих стилей не нужно: `.ui-modal.enter/.behind/.fresh/.stacked/.leave/.return` — в ui-kit.css;
   на телефоне (окна во весь экран) верхнее въезжает справа. Высоту не анимировать — только
   `transform`/`opacity`. Содержимое меняется по клику внутри — `cls: "tall"` (постоянная
   высота, окно не перецентровывается). Одиночное окно — то же самое при n = 1: плавно
   въезжает и уходит.

Где уже стоит (2026-10-07): money — «к прошлому году» (окна); «Еда» v1.31 — «Править» поверх
карточки продукта, «Завести продукт» поверх подбора, все окна въезжают и уходят плавно (своего
массива нет: нижнее окно выводится из состояния, «только что открытое» — по смене ключей слоёв);
«Здоровье» v1.41 — боковые панели стопкой (ниже). Вьюер портфеля 3.0 — карточка бумаги
(`openCard`: окна стопкой, слоты `lead`/`aside`/`top`); окно документа (`#modal-overlay`,
режим чтения) входит в общую стопку со слоями карточек (`docOpen`/`docThaw`, вьюер 3.116).

### Появление окна без рывка (ui-kit 1.38.0)

Ни одно окно кабинета не появляется и не исчезает рывком. Три случая:

- окно формы, нарисованное перерисовкой (`uiModalHTML`), — `cls: "enter"` только при открытии
  (страница сравнивает открытое окно с прошлой перерисовкой: «Здоровье» — `formKey`, «Еда» —
  ключи слоёв), закрытие — `uiStackPop(…, 0, …)`;
- окно, которое страница держит в разметке под `hidden` (`.ui-docwin` travel/games, профиль
  travel), — `uiShow(el)` / `uiHide(el, done)`; своё окно не из ui-kit — класс `.ui-fx` на слое
  затемнения, окно — его дочерний `[role="dialog"]`;
- справка — сама (`uiHelpOpen` / `uiHelpClose(true)`), на всех страницах.

Окно документа «Здоровья» рисуется перерисовкой — `.enter` ставит `openDoc` (`S.docFresh`),
уход — `uiHide` перед `closeDoc`. Раскрытие блока в потоке страницы (не окно) —
`uiExpandIn`/`uiCollapseOut`.

### Боковые панели стопкой (ui-kit 1.37.0, образец — «Здоровье»)

Карточка справа поверх страницы — `uiPaneHTML({ title, eyebrow, lead, aside, back, body, close,
width, oneLine, cls, bodyId })` (слой 200, под окнами форм 210; на экране уже 820px — во весь
экран). Своих копий разметки панели на странице не заводить. Стопка — те же `uiStack*`, что у
окон, слои ищутся по `.ui-pane`:

- состояние — массив панелей (`S.panes = [{ k, id }]`); открыть из каталога — массив из одной,
  переход из панели в панель — `push` (новая въезжает справа, нижняя сдвигается влево и
  тускнеет);
- `back: { label, sub? }` — кнопка «← …» к нижней панели (`data-act="pane-back"`), вместо `lead`
  (стрелок листания): листание — только у панели, открытой из каталога;
- «←», Escape — назад на одну (`uiStackPop(…, n - 1, …)`); ✕ и затемнение — закрыть все
  (`uiStackPop(…, 0, …)`: уходят все слои);
- прокрутка тел — `uiStackKeepScroll("pane-b-", n)`.
- панель, открытая из окна документа (`.ui-docwin`, слой 215: отчёт со ссылкой на биомаркер), — класс
  `.over` (слой 220) к `uiStackCls`: документ остаётся под ней, Escape и ✕ панели возвращают в
  документ, следующий Escape закрывает его (1.65.0, образец — `paneCls`/`panesOverDoc` «Здоровья»).

Новый компонент для страницы — добавлять в ui-kit, а не в страницу. Контракт —
