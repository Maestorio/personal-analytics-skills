# Карта «компонент вьюера → ui-kit» (этап 1 переделки вьюера)

Этап 1 плана из `docs/investment/TODO_design.md` §1 «Решения сессии 2026-10-12».
База: вьюер 2.23.11, ui-kit 1.38.0, `viewer.css` 627 строк, `viewer.js` 24 666 строки.
Базовый прогон тестов до правок (2026-10-12): `test_pages_contracts` 1960 · `test_doc_window` 26 ·
`test_reader_layout` 40 · `test_topbar_layout` 274 · `test_select_layout` 298 — все прошли.

**Итог (2026-10-12, вьюер 3.0.0 / ui-kit 1.39.0):** всё из «Что добавить в ui-kit» добавлено
(пункт 7 — `.ui-alert.info/.warn`; отрицательные сегменты `.ui-stack` не понадобились: разложение
доходности в карточке осталось своим `.ret-stack`). Переведено: строка разделов, заголовки,
плитки, карточка бумаги, «Доли и цели», «Выплаты», ИИС-3, «Действия», «Изменения», «Макро»,
распределения облигаций; в 3.2.0 (2026-10-13) — все карточки разделов (`.ui-card`/`.ui-alert`/`.ui-stat`)
и таблицы «Акций»/«Облигаций» (`.ui-table.dense`, ui-kit 1.41.0). Своими остались фильтры-чипы таблиц, `.meter`,
вердикт-теги, `.scn-*`, режим чтения (🔒) — список в `docs/investment/TODO_design.md` §1.

**Решения:** ✅ уже общее · ➡️ перевести на ui-kit · ➕ добавить в ui-kit (нет аналога, нужен
новой раскладке) · 🏠 доменное, остаётся во вьюере (перекрасить под токены) · 🗑 уходит вместе
с удаляемым блоком · 🔒 не трогать (решение владельца).

## Что добавить в ui-kit (сводно)

1. `.ui-tabs` — строка разделов на 10+ пунктов со скроллом вбок и пунктом «Ещё ▾».
2. `.ui-table` — сортировка, липкая шапка, место под полосу прокрутки, итоговая строка.
3. `.ui-name` — ячейка «имя / тикер бледнее».
4. `.ui-ci` — интервал рядом с крупным числом.
5. (`.ui-kv` уже есть — переиспользовать.)
6. Листание окна ← → со сдвигом содержимого (функция + классы, рядом с `uiStack*`).
7. Уровни `.ui-alert.info`/`.warn` (сейчас только ошибка); отрицательные сегменты `.ui-stack` —
   по итогам проверки на этапе 2.

Каждое — в ui-kit.css/js с поднятием версии ui-kit и контрактом в `test_pages_contracts.py`;
страницы, у которых уже есть похожее, этим этапом не трогаются.

## Риски этапа 2

- `viewer.js` строит DOM через `el()`, а ui-kit-компоненты отдают HTML-строки → мостик есть только
  во вьюере (`uiSelectNode`, `viewer.js:106`); обобщить до `uiNode(html)` в ui-kit, без двойной разметки.
- Переход `#modal-overlay` → `uiModalHTML`: 29 мест вызова, scroll-lock подложки и Escape в
  режиме чтения — проверить `test_doc_window.py`/`test_reader_layout.py` после переноса.
- Липкий `#top-chrome` + липкая шапка таблиц — у `.ui-table` нужен отступ сверху переменной,
  а не числом (высота chrome меняется: горизонт показывается не на всех вкладках).
- Контракт «справка ↔ вкладки»: переименование вкладок ломает ссылки в справке вьюера (`tools/assets/help/viewer/`) и
  `portfolio-workflow-guide.md` — синк в этапе 6, до него старые имена в справке — известный долг.
