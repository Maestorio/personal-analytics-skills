# Buttons

Кнопки и ссылки-действия.

`.ui-btn.lg` — одна главная кнопка формы; `.ui-btn` — обычное действие; `.ui-btn.ghost` — вторичное; `:disabled` с явным фоном. `.ui-link` — переход внутри страницы (к разделу, карточке). Стрелки листания `.ui-pager-btn` и крестик `.ui-modal-x` — только в шапке окна. `.ui-say` — фраза «что сказать Claude»: нажатие копирует текст.
