# RetStack

Полоса разложения ожидаемой доходности `.ret-stack`: макро (`c-6`) + дивиденды (`c-3`) + катализаторы (`c-5`).

Составляющая меньше 0,05% на полосе не рисуется (в легенде остаётся бледной); отрицательная — `.neg` серым курсивом. Итог — справа в заголовке `.decomp-total-val`. Все проценты — за горизонт, не годовых: подпись обязательна.
