# Tiles

Плитки главных чисел раздела `.ui-grid.kpi` > `.ui-card.ui-tile` с `.ui-big` («как в Деньгах»).

Подпись капсом `.ui-stat-k`, число `.ui-big` с единицей `.ui-unit`, под ним `.ui-sub` и дата в `.ui-note`. Кликабельная плитка — `button.ui-tile`. Мини-график `.ui-spark.sm` за 6 месяцев по календарю с нулевой линией `line.zero`. Первая плитка раздела — `.acc` (полоска `--sec-acc`). Интервал у ожидания — `.ui-ci` рядом с числом, всегда.
