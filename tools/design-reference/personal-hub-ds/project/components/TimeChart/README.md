# TimeChart

График показателя во времени `uiTimeChartHTML`/`uiTimeChartMount`: ось X — даты замеров (цена по снапшотам, маркер здоровья).

≤20 замеров — вся история; больше и не влезает — «полгода» с прокруткой и переключателем. Паузы — разрыв, частые замеры — медианы. Вторая серия — `.alt` пунктиром (здесь — «моя средняя»). Своих SVG-графиков по датам страницы не заводят.
