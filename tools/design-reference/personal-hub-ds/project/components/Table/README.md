# Table

Таблица данных `.ui-table.dense` в обёртке `.ui-table-wrap`.

Колонка «Бумага» — `.ui-name`: название, под ним тикер бледнее; стоимость — так же с долей второй строкой. Числа — `.num` вправо, шапка — капс без засечек, сортировка по клику на `th[aria-sort]`, липкая шапка `.sticky`, итог — `tfoot`. Шире экрана — липкая копия шапки `uiTableStickyHead`. Поиск по таблице — `.ui-qbox` в строке заголовка карточки.
