# Condition

Отложенное условие `.card-cond`: состояние, триггер, вердикт «сейчас → потом», действие, фразы для Claude.

Состояния — `.cond-badge` ждём / созрело / сработало / истёк / закрыто. Ценовой триггер показывает текущую цену и расстояние. Событие, которого ждём, — `.cond-evt` (`.pub` — вышло). Фразы «что сказать Claude» — в `Fold`. В переделке карточки действие становится таблицей «если → то» с суммами.
