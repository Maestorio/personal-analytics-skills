# Catalyst

Катализатор `.catalyst`: что может двинуть бумагу, окно, вероятность, эффект.

Левая черта `border-strong`; эффект — `.cat-chip.pos`/`.neg`; «зависит от сценария» — чип. Подсвеченный (`.hl`) — открыт по ссылке из «Изменений». В переделке карточки — на подвкладке «Риски», числа p/эффект уходят в подсказку.
