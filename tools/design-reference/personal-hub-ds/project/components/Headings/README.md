# Headings

Заголовки и уровни текста страницы раздела.

Имя раздела — `.ui-h1` (Spectral), под ним `.ui-lead` курсивом со строкой «данные на …». Карточка раздела начинается с `.ui-h2`; группы внутри карточки — `.ui-sechead h3` или `.ui-kicker` капсом. Текст — `.ui-text`, подписи — `.ui-sub`, пояснения — `.ui-note`. Эмодзи в заголовках не используются.
