# Stats

Ряд плиток карточки бумаги `.ui-grid.stats.card-tiles` > `.ui-stat.card-tile`.

Четыре плитки одной высоты (на ~1100px — 2×2): вес факт/план/IE, моя доходность, ожидание на горизонте с интервалом `.ui-ci`, потенциал IE. Знак числа окрашивается `.good`/`.bad`; подпись под числом — `.ui-note`. Облигация: доля в облигациях, доходность к погашению с купоном, погашение/оферта с дюрацией, моя доходность.
