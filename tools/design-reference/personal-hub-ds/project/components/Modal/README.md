# Modal

Окно карточки бумаги `uiModalHTML` 1150px по центру, стопкой (`uiStackCls`/`uiStackPop`).

Шапка: стрелки листания слева (`lead`), название с ценой, тикер · сектор, счётчик справа (`aside`), ✕. Закреплённая полоса `top`: метки, четыре плитки (`Stats`), подвкладки (`Seg .sm.acc`); на телефоне плитки сворачиваются при прокрутке (`.fold`). Тело — две колонки `.card-cols`: слева блоки `.modal-section` с заголовком-капсом, справа липкая колонка `KV`. Содержимое меняется по клику — `cls: "tall"`. На телефоне — во весь экран.
