# Tags

Метки вьюера портфеля: вердикт, фундаментал, гейт, условия.

Цвет метки — только из семантических пар (`success`/`warn`/`err`/`info` на своих `-bg`): BUY и HIGH — `success`, TRIM и MEDIUM — `warn`, SELL и RED FLAG — `err`, HOLD и LOW — нейтральные. Пара «сейчас → при срабатывании» — два тега со стрелкой, второй `.soft`. Значок гейта `.gate-badge` ставится справа от вердикта и всегда сопровождается словом в подсказке — цвет сам по себе смысла не несёт.
