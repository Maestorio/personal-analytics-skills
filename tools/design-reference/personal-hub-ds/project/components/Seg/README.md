# Seg

Сегментный переключатель `.ui-seg`: период, режим, подвкладки.

Выбранная кнопка — `aria-pressed="true"`. `.sm` — компактный; `.sm.acc` — подвкладки карточки бумаги: выбранная подсвечена подложкой `--sec-acc`, иначе на карточке не читалась. Больше 6–7 пунктов — не сегмент, а строка разделов (Tabs).
