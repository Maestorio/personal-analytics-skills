## 1. Вывод

Идея верна **частично**:

1. **Лимит Pro почти не освободится.** Без потери качества переносятся только задачи, которые и сейчас
   тратят мало. Основной расход — разработка в репозитории (≈52 коммита за 2026-09-20…10-20, больше всего
   `skills/travel-planning`, `docs/investment`, `tools/assets`) и скиллы-рассуждения. Ни то ни другое
   на открытые модели (Qwen, DeepSeek, GLM) без явной потери качества не переносится.
2. **Экономия в рублях копеечная, работы много.** Токены российских API для рутины — сотни рублей в месяц.
   Основная цена — время и лимит Pro на сборку и поддержку интеграции, плюс второй источник истины
   по логике скиллов (узкие промты рядом с SKILL.md).
3. **Реальный выигрыш — в удобстве и в коде без LLM.** Большая часть кандидатов переносится не на API,
   а в обычный детерминированный код. На LLM по API реально уходят 2–3 задачи.

Рычаги против «Pro кончается к пятнице», по убыванию эффекта:

1. **Max 5x** (+$80/мес к Pro): лимит ×5 и **$100/мес API-кредитов Claude** — фоновые задачи можно гнать
   на Haiku/Sonnet без второго набора промтов (см. §2).
2. **Меньше постоянного контекста:** SKILL.md по 56–79 КБ (`portfolio-scenario-stress`, `travel-planning`,
   `ru-portfolio-advisor`, `retrospective-forecast-audit`, `portfolio-integrated-view`) — налог на каждый прогон.
3. **Маршрутизация моделей** — уже в `_shared-references/model-routing.md`.
4. **Детерминированное — в код** (план — `deterministic-plan.md`).
5. **Российский API** — как дешёвый движок для 2–3 фоновых задач, если остаёмся на Pro.

Первое действие перед любым решением — **замер расхода 2 недели** (Settings → Usage) с пометкой
«разработка / скилл X».

## 2. Факты, которые меняют картину (проверены 2026-10-20)

- **На Pro `claude -p` и Agent SDK по-прежнему тратят лимит подписки.** Объявленное отделение отложено
  (обновление 15.06.2026). Утверждение в `docs/compactisation.md` и строка `forecast-monitor` в
  `_shared-references/model-routing.md` («вынос в `claude -p` вне лимитов подписки») — **неверны**.
  Источник: <https://support.claude.com/en/articles/15036540>
- **С 07.10.2026 Max 5x даёт $100/мес, Max 20x — $200/мес API-кредитов** на Claude API, Managed Agents,
  Agent SDK. Pro, Free и Enterprise не подходят. Claude Code кредитами не оплачивается, остаток
  сгорает в конце цикла. Источник: <https://platform.claude.com/docs/en/about-claude/api-credits-for-subscribers>
- **Регион:** РФ не в списке поддерживаемых стран Anthropic. Для Max риск такой же, как для текущей
  подписки, но API-ключ на NAS — ещё одна точка, по которой аккаунт могут заметить.
- **`macro-ru-watcher` уже на 5/7 детерминированный:** `fetch_macro.py` берёт IMOEX, RGBI, USD/RUB,
  CNY/RUB, ключевую ставку с ISS MOEX и ЦБ. Через поиск идут только инфляция и Brent.
- **Инфраструктура на NAS есть:** `hub-api` (единственный писатель со стороны сайта, `base_hash`,
  запись через DSM File Station) и `hub-notify` (cron, push, PyYAML). Вызов LLM или скриптов
  встраивается туда, отдельный сервер не нужен.

## 4. Риски переноса на API

- **Дублирование логики.** SKILL.md написаны под Claude; для API пишутся узкие промты со схемой ответа →
  правило живёт в двух местах. Каждый API-вызов — в реестр тестов и в справку страницы.
- **Безопасность.** Эндпоинт LLM за Caddy — только фиксированный список сценариев, не произвольный промт;
  лимит на ключе, журнал токенов, защита от инъекций из веб-страниц (импорт рецепта по ссылке).
- **D3.** Запись — только через существующие валидаторы и `/api/*/save` с `base_hash`, после подтверждения
  в интерфейсе. Модель напрямую в `Claude-Memory/` не пишет.
- **Провайдеры.** Selectel Token Factory, вероятно, ещё в preview; Cloud.ru меняет цены в одностороннем
  порядке. Один OpenAI-совместимый клиент с конфигом `base_url`/модель.
- **Сборка интеграции сама тратит Pro** — заметно в первые недели.

## 5. Порядок действий

1. Замер расхода 2 недели с разбивкой «разработка / скиллы».
2. Детерминированное — в код: загрузка портфеля, цены US eShop, `macro-ru-watcher`, сроки
   `forecast-monitor` (план — `deterministic-plan.md`).
3. Пилот российского API на трёх задачах: импорт рецепта, проверка событий `forecast-monitor`,
   «что заметно в тратах». Модели: Qwen-3.8-Flash-Next, DeepSeek-V4-Flash. Записать: повторы
   после валидатора, качество JSON, токены, стоимость.
4. Если Pro всё равно кончается — сравнить «Pro + код + российский API» с «Max 5x» по замеру.
5. Здоровье и инвестиционное ядро не трогать.

## 6. Когда пересмотреть

- Anthropic меняет правила `claude -p` / Agent SDK на Pro или условия API-кредитов.
- Цены Pro/Max или лимиты подписок заметно меняются.
- У российских провайдеров появляется модель уровня Sonnet на длинных русскоязычных инструкциях
  (проверка — прогон 2–3 реальных задач скилла с валидатором).
- Замер показывает, что основной расход — скиллы, а не разработка (тогда §3 пересмотреть в сторону API).
