### 2.2. Новый модуль: `skills/travel-planning/scripts/taxonomy.py`

Stdlib-only (как остальные скрипты). API:

```python
load() -> dict                      # кэшированное чтение taxonomy.json
label(group, key, lang=None) -> str # 'poi_category','RED_FLAG' -> 'КРАСНЫЙ ФЛАГ'
                                    # lang=None -> default_display_lang
canon(group, text) -> str | None    # обратный резолв ЛЮБОГО языка/алиаса в
                                    # канонический ключ; нормализация: trim,
                                    # collapse пробелов, casefold, ё→е,
                                    # '_'≈' ' (STRONG_CONFIRMED==STRONG CONFIRMED)
pattern(group) -> str               # regex-альтернация ВСЕХ ярлыков всех языков
                                    # (для вставки в парсерные регулярки),
                                    # длинные варианты раньше коротких
```

Требования: идемпотентность, отсутствие коллизий reverse-map (тест), понятная
ошибка при неизвестной группе. Импортируется и из `scripts/`, и из
`scripts/export/` (учесть оба пути запуска — смотри, как `export/stages/*`
импортируют соседей сейчас).

## 6. Известные грабли

1. **Reverse-map коллизии:** «СЛАБОЕ» (badge WEAK) vs «СЛАБЫЙ СИГНАЛ»
   (LOW_SIGNAL) — pattern() обязан сортировать альтернативы по убыванию длины;
   canon() резолвит только внутри своей группы, кросс-групповой резолв запрещён.
2. **ё/Е и регистр:** canon() нормализует casefold + ё→е; рендер — всегда
   канонический `ru` из словаря (с Ё, как записано).
3. **Род прилагательных:** ярлыки POI выбраны noun-формами (§2.1), чтобы
   «гора … [СИЛЬНОЕ ПОДТВЕРЖДЕНИЕ]» читалось нейтрально. Не «улучшать» на
   причастия.
4. **Идемпотентность polish stage4:** правило `CONTESTED→Спорные` не должно
   корёжить уже русские заголовки (проверить тестом).
5. **Три независимых парсера Stage 1** (см. format-firewall §2): tonality-
   трейлеры остаются EN, эти пути не затрагиваются; не «помогать» им заодно.
6. **Импорт taxonomy.py из export/:** у export-скриптов свой механизм импорта
   соседей — повторить его, не изобретать sys.path-хаки.
7. **HTML-шаблон Stage 2** — единственное место, где ярлыки уходят в JS;
   менять только подписи (`catLabel`, кнопки), не data-ключи фильтров.
