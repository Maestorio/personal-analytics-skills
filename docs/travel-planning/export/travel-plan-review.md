## II. Содержание

**Глубина POI / отелей / ресторанов**

**Логистика**

- Операторы: luxury абстрагирует («вас встретят»); self-guided берут на себя трансферы/такси и описывают это явно.

- **Решение:** сохраняем; добавляем мини-пометку зависимостей. Учитываем, что после броней секция перепишется в исполненную форму.

**Размещение**

- Операторы: luxury — страница на отель с «почему выбран»; self-guided — hand-picked accommodation с акцентом на логистику добраться.
- Моё мнение: у вас сильно, но «почему выбран» тоньше «почему исключён»; альтернативы не разведены.
- Разрыв: средний.
- Рекомендация: «выбран за / компромисс» + развести альтернативы по оси.
- Ваш комментарий: логика нравится, **но только для незабронированного отеля**; если забронирован — секция выбора не нужна, оставить лишь как добраться (если далеко), что внутри, включён ли завтрак по броне.
- **Решение:** два режима блока 🏨. **До брони:** логика выбора + компромисс + дифференцированные альтернативы + TODO-цена. **После брони:** только доступ (как добраться, если далеко), удобства, завтрак-по-броне; логику выбора убираем.

## Идеальный порядок разделов (полевая версия)
