## 4. Для чего LLM необходим принципиально (в этой части)

| Что | Почему нельзя скриптом | Деградированный режим |
|---|---|---|
| Вердикты и разбор бумаг, катализаторы, оценка качества, новости по эмитентам (advisor, Mode 1/2/4/8) | суждение + веб-поиск + чтение отчётности | Вьюер показывает **последний сохранённый** обзор/гейт с датой (механизм «возраст файла» уже есть: плашки, `:2547`); при отсутствии обзоров «Акции» пусты (`:5507`), «Облигации» уже падают в снапшот-only |
| Интегрированный вид, когерентность, стресс, прогнозы/сценарии | синтез и оценка вероятностей | Показ старых файлов с возрастом; нового взамен нет. Другой агент разбирает |
| Монитор прогнозов (`monitor-reports/`), событие условия «вышел отчёт» | веб-проверка событий | Предупреждения/«отчёт вышел» перестанут появляться; ценовые и датные условия работают |
| Тезис/причина решения («Отказываюсь» — почему), формулировка новых условий словами, `branches` | человеческий текст | Форма с полями (п. 3) — это перенос на человека, не на скрипт |
| Недельная инфляция Росстата, Tier-2 зарубежные (US 10Y, VIX) | нет чистого API | Ручной ввод или пропуск строки («нет данных», без подстановок — принцип `build_macro.py`) |
| Решения по флагам «Тип бумаги изменился», «Корзина облигации изменилась» | подтверждение человеком | Уже на сайте, без LLM |

Деградированный режим «из коробки» (без новой разработки): все LLM-вкладки показывают последний файл; возраст виден в плашках и подзаголовках; Фонды, ИИС-3, Доли и цели, Загрузки, Уведомления, снапшотная часть «Сегодня» и «Динамики» работают. Недоработки режима: п. 6 и п. 3.

## Краткое резюме

1. Без LLM сегодня работают: сборка снапшота на сайте (IntelInvest xlsx → `build_snapshot.py` на NAS, 2–3 мин), живые цены MOEX, доли/коридор/«Сейчас» (JS-зеркало советника), правка плана, импорт IE, фонды, ИИС-3, выплаты по купонам, динамика XIRR, журнал решений (пересборка), индекс бумаг, push и макро-автосрез.
2. Переключение «сайтовой сборки → рабочий снапшот» уже сделано (v4.0.0, `pf_build.save`); README API-1 устарел. Пробный только автосрез макро (до 21.11).
3. Единственный неустранимый ручной вход — выгрузка сделок из IntelInvest; допустимо добавить кнопку «пересобрать на последних сделках» (S) и ночную автосборку (M).
4. LLM-файлы (обзоры, стресс, IV, прогнозы, монитор, `macro-ru-watcher`-срезы) вьюер показывает как последние сохранённые — с возрастом; «Акции» пусты без обзоров (S: снапшотная таблица), «Облигации» уже деградируют в снапшот-only.
5. Главный риск режима без ИИ — гейты не стареют: `auto_maintain_gate_reviews.py` запускается только через `save-to-library`, а клиент и движок «Сейчас» срок `valid_until` не применяют, поэтому докупка остаётся открытой после истечения оценки (S: эффективный статус в клиенте/движке; M: ежедневный job).
6. Условия (`conditions.yaml`) сегодня правит только LLM, кнопки лишь копируют фразу; готовый детерминированный `apply_condition.py` + PyYAML в hub-notify позволяют сделать формы «добавить/исполнить/перенести/закрыть» (M).
7. Журнал решений: пересборка автоматическая, ручные входы (отказы, инциденты, тезисы) пишет только LLM — нужны формы и whitelist-путь (M); блок вердиктов опустеет без обзоров, теневые базы работают.
8. Макро: Tier 1 есть (Brent — фьючерс BR, инфляция — месячная ЦБ, недельной нет, Tier 2 нет); переключить графики на автосрез — S, ручной ввод инфляции — S–M, но ряды несопоставимы (нужна пометка/отдельная серия).
9. Внешние зависимости без LLM: MOEX ISS (критична), cbr.ru (есть офлайн-фолбэк), IntelInvest (ручная), push-сервисы Apple/Google, PyPI при холодном старте hub-notify.
10. Для режима «без ИИ» нужен флаг, прячущий «Что сказать Claude», CTA гейтов, блок «Обновить прогнозы и отчёты», красные плашки LLM-файлов, часть справки и тексты push с «Сказать Claude»; формы ручного ввода заменяют LLM там, где запись была единственной функцией модели.
