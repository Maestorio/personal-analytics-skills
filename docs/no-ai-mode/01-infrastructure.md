## 1. Слои системы и их зависимость от Claude

| Слой | Где живёт | Нужен ли Claude | Внешние зависимости |
|---|---|---|---|
| Страницы кабинета (`tools/*.html`, `assets/`) | NAS, Caddy `/srv` только чтение | нет | браузер; HTTPS-домен `*.synology.me` (DSM reverse proxy + Let's Encrypt) |
| Caddy (зоны доступа, пароль, листинги) | контейнер `portfolio-viewer` | нет | образ `caddy:2-alpine` (уже на NAS) |
| `hub-api` — единственный писатель с веба (`/api/*`, валидаторы, `base_hash`, `.versions/`, File Station) | контейнер `python:3.12-alpine`, только stdlib (без PyYAML) | нет | DSM File Station на том же NAS |
| `hub-notify` — расписание 08:30 МСК, push, задачи сайта (eShop, макросрез, сборка снапшота) | контейнер; зависимости в томе `notify_deps` (cryptography, PyYAML, openpyxl, numbers-parser) | нет | PyPI только при первом старте или смене версий; MOEX ISS, cbr.ru, api.ec.nintendo.com |
| Офлайн-кабинет (`sw.js`, `sw-offline.js`, очередь `POST /api/save`) | браузер | нет | только HTTPS-домен |
| Synology Drive (зеркало Mac ↔ NAS) | Mac + NAS | нет | нужен скиллам и деплою, не сайту |
| `deploy.zsh` (код → NAS) | Mac | нет | rsync через CloudStorage-маунт |
| Скиллы Claude Code | Mac | **да** | подписка Anthropic |
| MCP-серверы (ZenMoney, память профиля) | внутри Claude | **да** | вне Claude недоступны (ZenMoney — заменим прямым API, см. `07-autonomy-local-api.md`) |

## 2. Три категории «без LLM» (используются во всех разделах серии)

1. **На сайте** — страница + `hub-api`/`hub-notify`. Работает с телефона, Mac не нужен.
2. **В терминале на Mac без ИИ** — Python-скрипты скиллов (stdlib, `openpyxl`, `reportlab`) запускаются
   руками, результат ложится в зеркало Synology. Это «без LLM», но не «без Mac и не с телефона».
3. **Только Claude** — рассуждение, веб-поиск, чтение сканов, MCP.

Цель режима «без ИИ» — перевести максимум из категории 2 в категорию 1 и честно пометить категорию 3.

## 3. Сценарии блокировок

| Сценарий | Что отваливается | Что остаётся |
|---|---|---|
| Нет доступа к Anthropic (подписка, блокировка, деньги) | все скиллы; MCP ZenMoney; память профиля Claude | сайт целиком, задачи сайта, офлайн-копии, ручные правки, скрипты в терминале |
| Нет доступа к GitHub | синхронизация кода (деплой идёт с локальной копии — не затронут) | всё |
| Блокировка иностранных хостов с NAS | `api.ec.nintendo.com` (цены eShop; 2026-10-21 работало), push-сервисы Apple/Google (Web Push), PyPI/Docker Hub при холодном старте | MOEX, ЦБ — российские |
| Падение DDNS `synology.me` / сертификата | внешний HTTPS-вход, офлайн-режим (только HTTPS), push-подписки | LAN `http://<IP>:8080`, Tailscale (описан в `SYNOLOGY-SETUP.md`) |
| NAS пересоздан (тома потеряны) | `notify_data` (ключ VAPID → переподписать устройства; кэши сборки), `notify_deps` (нужен PyPI) | данные `Claude-Memory/` |
| Нет Mac | деплой кода, скрипты категории 2, Synology Drive (скиллам) | сайт и задачи сайта работают полностью |

## 4. Пороги свежести — общие для хаба, вьюера и hub-notify

`tools/hub.html` (`CONFIG.reports`, `staleAfter`/`failAfter`), `tools/assets/viewer.js` (`STALE_THRESHOLDS_DAYS`, `STALE_FAIL_DAYS`), `tools/hosting/notify/notifier.py` (`STALE_WARN_DAYS`, `STALE_FAIL_DAYS`)
(сторож — `test_pages_contracts.py`, `test_notifier.py`).

| Артефакт | «пора обновить» | «скиллы на нём не работают» | Кто обновляет без LLM |
|---|---|---|---|
| снапшот портфеля | 7 дн | 30 дн | сайт («Загрузки» → сборка из выгрузки IntelInvest) |
| weekly-review акции / облигации | 14 дн | 30 дн | никто |
| стресс-тест | 30 дн | 60 дн | никто (возможен пересчёт на NAS — `02b` §2.1) |
| integrated-view | 30 дн | — | никто |
| monitor-report | 10 дн | — | никто (сроки без поиска — `02b` §2.3) |
| макро-снимок (`macro-snapshots/ru-*.md`) | 7 дн | — | автосрез пишет в `auto/`, плашка его **не видит** (`viewer.js`, `_staleList`) |

Без LLM через 30 дней хаб и вьюер показывают «жёсткие» плашки по обзорам, а hub-notify шлёт push
«просроченные отчёты» (вид `stale`, отключается переключателем). Это не поломка, а шум — режим
«без ИИ» должен его убрать (см. README §5).

## 5. Где жить переключателю «без ИИ»

Готового хранилища настроек нет. Общие ключи `localStorage` на origin: `hub-theme` (`uiSetTheme` в `ui-kit.js`,
ранний скрипт в `<head>` каждой страницы), `hub-auth`, `hub-cb`, `hub-last-refresh`, `cab-warm-at`.
Серверные настройки есть только у уведомлений (`/api/push/settings`, хранит hub-notify).

| Вариант | Суть | Плюсы | Минусы | Размер |
|---|---|---|---|---|
| **A. `localStorage["hub-noai"]`** по образцу `hub-theme`: `uiSetNoAi(on)` в ui-kit, атрибут `data-noai` на `<html>` из раннего скрипта, CSS/JS страниц читают атрибут | мгновенно, офлайн, одна точка внедрения | настройка на каждое устройство отдельно | S |
| B. Серверный файл (`_hub/settings.json` через hub-api, whitelist + валидатор), кэш в localStorage | общий для устройств; читают hub-notify (глушить push `stale`) и скиллы | нужны whitelist, тесты, фолбэк без связи | M |
| C. A + B | синхронно и мгновенно | максимум кода | M |

**Решение владельца 2026-11-07: переключатель — на весь сайт (вариант B), главная цель — исключить
перезатирание данных, правленных на сайте, скиллами и скриптами.** Значит, флаг должен быть виден не только
страницам, но и hub-notify и скиллам на Mac (через зеркало Synology). Отсюда конструкция:

| Элемент | Решение |
|---|---|
| Носитель | `Claude-Memory/_hub/settings.json` (`hub-settings@1`: `ai_mode: on|off`, `off_since`, `returned_at`, `by`, `note` — как `START.md` §2.1). Лежит в дереве данных, поэтому виден скиллам через mount и hub-notify через `/srv`; пишет только hub-api (`GET/POST /api/hub/settings`, `base_hash`, `.versions/`), зона — пароль с любого IP (как `/api/pv/*`) |
| Страницы | ui-kit читает файл при загрузке (один запрос, кэш в `localStorage["hub-noai"]` на случай отсутствия связи и для раннего `data-noai` на `<html>`); кнопка в шапке хаба «Режим: с ИИ / без ИИ» |
| hub-notify | читает файл в дневном проходе: в режиме «без ИИ» не шлёт виды по LLM-файлам, меняет тексты push, задачи сайта (сборка, стресс-пересчёт, макро, eShop) работают как обычно |
| Скиллы и скрипты-писатели | общий помощник `hub_settings.py` в `_shared-references/` (инжектируется в бандлы как `constraint_engine.py` через `bundle_scripts`): `ai_mode(root)`. Каждый писатель `Claude-Memory/` в начале работы читает флаг; `off` → **отказ писать** с сообщением «сайт в режиме без ИИ: правки идут с сайта, скилл только читает» (переопределение — явный флаг `--force` с записью в журнал). Список писателей и что гейтится — `START.md` 1.3; правило: отказывают писатели, чей вход — вывод модели, владельческие CLI работают в обоих режимах (`PLAN-less-ai.md`, шапка) |
| Правило транспорта | строка в `_shared-references/transport-layer.md`: «перед первой записью прочитать `_hub/settings.json`; `ai_mode: off` → остановиться». Сторож — тест на каждый писатель (одна таблица «скрипт → проверка флага») |
| Обратное переключение `off → on` | скиллы не пишут «поверх», а **сверяют**: оверлей игр (`user-state.json`), ручные точки `labs.json` (`source: manual`), решения владельца (`decision_write.py owner`) — читаются как первичные; это и есть «шаг сверки» в SKILL.md соответствующих скиллов |

Размер: файл + ручка + ui-kit — S; помощник + отказ во всех писателях + тесты — M (много мест, но
однотипных); шаги сверки в скиллах — по разделу (игры M, здоровье S, портфель — см. эррату по ветке
`data-structures`).

Что переключатель меняет на страницах (общий список; детали по разделам — в приложениях):

- кнопки `.ui-say` «что сказать Claude» в справках (`.ui-say` в `ui-kit.js`) и блоки «Что сказать Claude» во вьюере;
- плашки «отчёт просрочен → перегони скилл» → «данные от DD.MM, без ИИ не обновляются» (серые, не красные);
- подсказки «наполняет скилл» (тексты «наполняет скилл» / «скажи Claude…» в `games.html`, `health.html`, `money.html` — искать по фразе);
- показ ручных форм там, где запись была функцией LLM (игры, анализы, условия, гейты, черновик поездки);
- виды push, зависящие от LLM-файлов (`verdict`, `monitor`, `cond_date`, `stale` для обзоров) — выключены по умолчанию;
- тексты push с «Сказать Claude: …» (одно место: вид `stale` в `notifier.py`) → нейтральные.

## 6. Что сделать по инфраструктуре независимо от разделов

| # | Что | Зачем | Размер |
|---|---|---|---|
| 1 | Сохранить колёса зависимостей hub-notify в `_nas/wheels/` и ставить из них (`pip install --no-index --find-links`) | холодный старт без PyPI | S |
| 2 | Не обновлять образы контейнеров во время блокировок; зафиксировать теги (`caddy:2.10-alpine`, `python:3.12.x-alpine`) | воспроизводимость | S |
| 3 | Проверить Tailscale как запасной вход и записать в `SYNOLOGY-SETUP.md` результат | если DDNS/сертификат отвалится | S |
| 4 | Переключатель режима на весь сайт (вариант B) | единая точка для страниц, сервера и скиллов | `START.md` 1.1–1.3 |
| 5 | Вид push `stale` разделить: «снапшот/макро» (без LLM обновляемы) и «обзоры/стресс/IV/монитор» (LLM) | чтобы в режиме без ИИ не глушить полезное | S |
