# Ревизия плана «Меньше ИИ» — 2026-11-09

**Объект:** 13 документов `docs/no-ai-mode/` (427 КБ) против кода ветки `claude/less-ai` (= `main` после PR #37
+ правки `pack.sh`/`ds_schemas`). Метод: логику, решения и порядок читал ведущий; ссылки на код и утверждения
о поведении сверяли пять субагентов по доменам, выборочно перепроверено. Живые данные на NAS и Mac из
репозитория не видны — что проверить локально, в §6.

**Итог.** План здравый: разделение «навсегда / только режим» верное, принципы §0 START держатся, узкие
проверки писателей первым шагом — правильно. Начинать работы по START как есть нельзя: восемь находок
блокируют (§2), порядок записан в четырёх местах по-разному, около двух третей ссылок на код сдвинулись, часть
задач ссылается на несуществующие маршруты и модули. Исправленный порядок и состав — `PLAN-less-ai.md`
(единственный источник порядка), задачи — `START.md` после синхронизации.
