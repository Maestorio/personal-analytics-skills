О системе: Персональная OS для принятия инвестиционных решений. Скиллы работают как конвейер — данные собираются, анализируются, синтезируются и копятся в единой базе знаний.

Нажмите на блок

● Данные — парсинг портфеля, макро-снапшот, сбор прогнозов
● Прогноз — взвешенный консенсус, стресс-тест гипотез, сценарии 2×2, ретроаудит
● Оркестрация — DAG-координация факторов, синтез данных
● Портфель — 8 режимов анализа, сценарный стресс по позициям
● Обслуживание — запись в базу, синхронизация, ревизия
● База знаний — все артефакты на Synology/Google Drive
