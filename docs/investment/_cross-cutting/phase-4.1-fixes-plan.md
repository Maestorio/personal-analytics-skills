### A4. Валидатор horizon_ends: правильный якорь + режим скользящий/якорный

**Проблема (2 слоя):**
- Баг: `assemble_artifact.py:884` — `base = review_date or date`. В stress-схеме
  `review_date` = дата **следующего ревью** (2026-12-05), якорь должен быть `date`.
  Итог: 3 ложных warning'а на корректном артефакте.
- Семантика: §11.6 описывает два режима (скользящий — даты переезжают каждый прогон;
  якорный — даты стоят, срок сжимается), но в YAML режим не объявлен — валидатор
  не может отличить «якорный по дизайну» от «ошибка дат».

**Файлы:** `_shared-references/yaml-schemas.md` (§11.0/§11.6),
`skills/save-to-library/scripts/assemble_artifact.py` (`_validate_horizons_block`
~:853–900) + tests, producers: `build_weekly_stock_stub.py`, `build_weekly_bond_stub.py`,
`build_stress_stub.py` (выставлять поле).

**Что сделать:**
1. **Схема (аддитивно):** новое top-level поле v2 `horizon_mode: rolling | anchored`,
   default при отсутствии — `rolling` (все существующие v2-файлы скользящие → валидны
   без миграции). Producer-стабы пишут его всегда: `rolling` при `--horizons`,
   `anchored` при `--anchor-dates`. Зафиксировать в §11.0 + перекрёстная ссылка из §11.6.
2. **Валидатор:** базовая дата = `review_date` для weekly-review, **`date` для stress**
   (исправить :884 — ветвление по `type`).
   - `rolling`: текущая проверка `base + N мес → конец месяца ±5д`.
   - `anchored`: проверку «±5д от base+N» НЕ применять; вместо неё —
     `N == month_diff(base, horizon_ends[hN])` с допуском ±1 мес + даты строго
     возрастают с N + все даты > base. (Якорь стоит, нумерация ключей следует
     из остатка — ровно дуальность §11.6.)
3. Тексты warning'ов: указывать режим и поле-якорь (чтобы LLM в следующий раз
   не сочинял объяснение, как в логе 2026-06-11).

**Acceptance:** stress-2026-06-08 (rolling, якорь `date`) валидируется с 0 warnings;
синтетический anchored-кейс с теми же датами на следующем прогоне (`N` уменьшился)
— валиден; перепутанные даты — ловятся. Тесты: `test_assemble_artifact.py` (+3-4 кейса),
`test_build_*_stub.py` (поле `horizon_mode` присутствует).
