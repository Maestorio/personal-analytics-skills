## 2. Разрыв с лучшими практиками

Каталоги практик трёх отчётов сходятся, но база источников общая — это не независимое подтверждение.

**Чего у нас нет:**
1. Теневых пассивных портфелей, с которыми сравнивается каждое решение (Fable §5 № 3, Orc № 2, DR № 4).
2. Предрегистрации правил, баз, метрик и критериев отключения (Fable № 6, DR §7). *Частично закрыто
   2026-10-07: правила отключения и заморозка — `forecast-calibration-calendar.md` §5–§6.*
3. Учёта попыток: без числа попыток бэктест не оценить (C57, CONFIRMED); каждая смена метода — попытка.
4. Журнала решений «предложила система → сделано → сделала бы база» (Orc §7, DR «Attribution»).
5. Склейки перепечаток и проверки происхождения при поиске (C38).
6. Разнородности моделей — всё на Claude (C37).
7. Проверки отметок МосБиржи о неполном раскрытии в гейте (C71, CONFIRMED) — не проверял, есть ли.

**Что есть, но практики не поддерживают:** Claude-red-team как верификатор; ручные сценарные веса,
превращённые в точечный вывод; значения по сценариям, выведенные из L1, плюс MC на 10 тыс. путей поверх
них; тонкая настройка весов доверия на выборках ~17 прогнозов.

**Что есть и совпадает с практиками:** все числа — код (38 тестов `T*`, 70 тестов `stress_digest`,
блокирующие валидаторы); блокирующий гейт одностороннего конуса; `fact_anchor` с датой; `outcome_log`
с заморозкой значений на момент прогноза и раздельным учётом снимков при замене.

| Доходность B3 − B2 | ~20 точек | Ничего: для IR 0,5 при мощности 80% нужно ≈ ((1,96 + 0,84)/0,5)² ≈ 31 год. Только грубый вред |
| Направление | 20 → ≥15 верных (p ≈ 0,021) | Только сильный эффект |
| Брайер против базовой частоты | 40–80 событий | Грубая некалибровка |
| Попадание в P10–P90 | ~30 исходов | ≤19 из 30 при номинале 80% отвергает калибровку на ~2% — самый информативный тест |
| Ошибка с весами против без | 20–30 исходов | Достаточно для решения R4 |
| Процессные ошибки | с первого месяца | Здесь система может доказать пользу |

**Основания отключить** — `forecast-calibration-calendar.md` §5 (записаны до данных). Через 12 месяцев
B3 − B2 < 0 и процессные ошибки не снижаются → свернуть систему до data-loader, stress и чек-листа гейта.

## 7. Pre-mortem: через 12 месяцев система оказалась вредной

1. **Ложная точность → аллокационная ставка, сломанная шоком вне осей** (повышение ставки, крепкий рубль,
   Ормуз); облигационная нога просела сильнее модели из-за заниженных спредов. Опора: C44 v5, C48; PSS-5, RES-3.

   ~10 исходов; тесты и валидаторы создавали ощущение проверенности. Опора: C57; самоаудит (62% churn).
3. **Общие слепые зоны одной семьи моделей и загрязнённые веса:** коррелированные проверки, веса из
   ретро-аудитов со знанием задним числом. Опора: C37, C39, C5.
