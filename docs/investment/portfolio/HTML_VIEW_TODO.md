## Принципиальный рефактор источника данных в модале позиции

**Проблема:** `weeklyReviewCurrent` сейчас выбирается как YAML, на который ссылается
integrated-view (`inputs.review_stock`). Это означает, что в модале позиции показывается
аналитика (катализаторы, фундаментал, idio α, div yield, вердикт) из старого обзора,
хотя всё это меняется еженедельно. Вердикт HOLD из нового обзора и катализаторы из
старого BUY-обзора — несвязная картина.

**Принцип, который нужно реализовать:**

| Тип данных | Должен браться из |
|---|---|
| Аналитика по бумаге (вердикт, уверенность, катализаторы, фундаментал, idio α, div yield) | последнего weekly-review всегда |
| Макро (сценарные дельты) | последнего stress-теста |
| Веса, XIRR | portfolio snapshot |
| "На чём строился интеграционный анализ" | ссылка/плашка (провенанс) |

**Техническое решение:**
- В `buildState` (строки ~972–979) убрать привязку `weeklyReviewCurrent` к
  `inputs.review_stock` из integrated-view.
- `weeklyReviewCurrent` = всегда новейший YAML по дате.
- Ввести `weeklyReviewAnchor` = тот, на который ссылался IV (для провенанс-плашки).
- Аналогично для `weeklyBondReviewCurrent`.
- Аналогично для `stressCurrent` — если есть более свежий stress, использовать его.

**Побочный эффект:** оба таба (Акции и IE Model) начнут показывать одинаковые актуальные
данные по позиции, и модал IE Model больше не будет нуждаться в хаке `showPositionFromIeModel`
с отдельным `latestPos` / `ieVerdict`. Эту логику можно будет упростить обратно.
