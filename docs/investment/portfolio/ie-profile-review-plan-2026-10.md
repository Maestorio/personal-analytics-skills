## Где запускать каждый шаг

Скиллы контура рассчитаны на **Claude Desktop в режиме Cowork**. Доступ к Synology
там идёт через `request_cowork_directory`, а `memory-sync` пишет в память claude.ai
(`memory_user_edits`). В Claude Code этой памяти нет. Правки репозитория (git, тесты,
`/pack`) — только в **Claude Code**: в терминале или во вкладке Code десктопа.

## 2. Подготовка (Sonnet, ~5 мин)

1. Проверить Synology mount: `Glob("~/Library/CloudStorage/SynologyDrive-home/Claude-Memory/domains/ru-sellside/invest-era-*")`.
2. Прочитать `[lib] Invest Era` в auto-memory (`MEMORY.md` → `lib_invest_era.md`): дата последнего аудита, текущий trust по subdomain'ам.
3. Перечислить аудированные вебинары: frontmatter `period` / `audit_date` каждого `invest-era-*.md`. Известно из репо: вебинар 12.03.2025 (аудит на 24.04.2026, `skills/retrospective-forecast-audit/EXAMPLES.md`); профиль построен на трёх вебинарах 2024–2025.
4. Записать: **дата последнего пересмотра** (→ точная дата T5) и **список неаудированных вебинаров** с датой ≤ дата_аудита − 3 мес.
5. Перепроверить T1–T4 по ссылкам из §1 (изменилось → перейти в ветку «смена режима», см. §6.2).

## 3. Сбор материала (пользователь) — ✅ выполнено 2026-10-02, см. «Статус материала»

- Выбрать 1–2 вебинара из списка шага 2.4; приоритет — самые свежие, у которых горизонт ≥3 мес. уже наступил.
- Положить расшифровки (`.txt`/`.md`/`.docx`) + дату + слайды (если есть) в рабочую папку сессии.
- `forecast-collector` **не нужен**: он для массового сбора по публичным источникам; вебинары IE — закрытый контент, вход даёт пользователь.

## 4. Аудит (Opus, Full-режим) — по коллекции `fc-invest-era-collection-2026-10-02.md` + расшифровки

- Модель: **Opus** — транскрипт ≥45 мин и обычно ≥9 тезисов (`skills/retrospective-forecast-audit/SKILL.md`, режим Full; на Sonnet Full при ≥9 тезисах не запускать).
- Запуск: `/retrospective-forecast-audit` + «вот расшифровка вебинара Invest Era от ДД.ММ.ГГГГ, аудит на сегодня».
- Если сбор консенсуса на дату вебинара затягивается (>5 turn'ов) — workflow B: отдельным сообщением собрать DR-досье консенсуса, затем вернуться в скилл.
- Специально проверить в аудите:
  - облигационный блок (HIGH) при ставке 14% vs 16–21% — держится ли альфа (подготовка к T3);
  - LOW-тикеры «бенефициары снятия санкций» (NVTK / FLOT / AFLT / UPRO) и «ложные бенефициары нормализации» — подтверждается ли антипаттерн;
  - системные дельты (USD/RUB −25…−30 ₽, ставка −2…−3 п.п., IMOEX −20…−30%) — не сместились ли;
  - кластер 7 (переоценка мирной премии) — на фоне переговоров 2026.
