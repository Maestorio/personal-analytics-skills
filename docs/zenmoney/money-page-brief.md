### `history.json` — что есть для страницы

```
records[]: month, as_of, mode (month|quarter), operations, flagged,
  clean_share_count, clean_share_rub,            // доли 0..1
  expense_rub, correction_rub,                   // траты месяца С корректировками (база spending + корректировки, кроме переводов себе); все корректировки, принятые тоже, кроме transfer_out
  correction_share_of_expense,                   // доля 0..1 = correction_rub / expense_rub; correction_rub нет в записях до 2.7.0
  correction_transfer_out_rub,                   // принятые «переводы себе вне учёта»: не траты, не в доле; строка «выведено из учёта»
  by_check {A1..A5: {count, rub}},               // типы замечаний
  b6_count, b7_count, b7_rub,                    // молчащие счета; траты вне баланса без тега поездки и инвестиций (с 2.7.0)
  c_counts {C9, C11, C12} | null,                // только quarter
  fixed_count, rechecked_count, fixed_share,     // по прошлым месяцам; null без истории
  not_rechecked_count, open_by_age {lt_1m, 1_3m, gt_3m}, open_total, unconverted {валюта: n},
  places_counts {twins, split, unlinked, rename, bank_text, chains} | null  // места платежа месяца (с 2.15.0), только числа; null/нет поля — «не проверялись»
  // open_total и open_by_age — снимок ВСЕЙ истории на момент записи, не месяца: показывать только из последней записи
issues{ "A3:<id>": {check, month, first_seen, last_seen, status open|fixed|accepted, closed_at} }
```

Подписи типов (на странице — только русские, без кодов):

| Код | Подпись |
|---|---|
| A1 | Переводы, записанные расходом и доходом |
| A2 | «Корректировки» |
| A3 | Без категории |
| A4 | Поездка основной категорией вместо тега |
| A5 | Одинаковые операции (вопрос) |
| B6 | Банк молчит |
| B7 | Траты вне баланса без тега поездки (не видны в отчёте) |
| C9 / C11 / C12 | Похожие названия / Неиспользуемые категории / Поездки не убраны в «Путешествия» |

### `spending.json` (`zenmoney-spending@1`)

```
months[]: month, as_of,
  totals {expense_rub, income_rub, refunds_rub,            // очищенные (принцип 5)
          expense_in_balance_rub, income_in_balance_rub,  // «как в приложении»
          expense_off_balance_rub, operations},
  excluded {corrections|investments|cashback|partner|refund_category|loans: {expense_rub, income_rub, count}},
  categories [{name, rub, count, share}],                 // верхний уровень, по убыванию
  categories_regular [{name, rub, count, share}],         // то же без поездок и разовых
  subcategories_regular [{parent, name, rub, count}],     // подкатегории обычных трат (с 2.10.0); трата прямо в родителе — name «без подкатегории»; строки родителя в сумме = его categories_regular. Страница: раскрытая категория и окно «к прошлому году»
  // totals также: expense_trips_rub, expense_one_off_rub, expense_regular_rub
  income_categories [{name, rub}],
  trips [{name, rub, count}],
  merchants [{name, rub, count, category, sub?, kind, rest?}],  // обычные (kind=regular): с 2.13.0 ВСЕ места, sub — подкатегория, траты без места — {name:"без места", rest:true} в своей подкатегории (2.8.0–2.12.0: 6 мест на категорию + «прочие»); в сумме итог категории; + все места разовых (kind=one_off); места поездок — в trips.json
  one_off [{name, rub, category, note}],                  // разовые поштучно (с 2026-10-06), note — из spending-rules.json (по операции или по месту — one_off_merchants)
  merchant_share_of_expense, unconverted {валюта: n},
  recomputed_at?                                          // YYYY-MM-DD: месяц переписан с другими итогами после закрытия (правка в ZenMoney); пересчёт, совпавший до рубля, не ставит (с 2.10.0)
```
Сравнение со средним за 3 месяца не хранится — страница считает сама по `months`. Решения пользователя: категории и места хранить можно; счетов и отдельных операций нет.

### `facts.json` (`zenmoney-facts@1`, с 2.11.0)

Производный файл: `audit_history.py` пересчитывает его после каждой записи `spending.json` и `history.json` (формулы и пороги — только `scripts/history_query.py`, `PARAMS`; страница факты не считает, только показывает — решение 2026-10-06, чтобы формулы не разошлись).

```
month                                  // последний закрытый месяц, на который посчитаны факты
params {…}                             // пороги, с которыми посчитано
facts [{kind, …}]                      // по порядку важности; виды:
  unrecorded_rising {series [{month, rub, share}]}
  minus_months     {window, count, count_prev, months [{month, flow, with ["trips"|"one_off"]}]}
  acceleration     {window, growth, growth_prev, per_month, per_month_prev}
  jump             {category, window, base, median_rub, recent_avg_rub, ratio, excess_rub, explain}
  growth           {category, window, base, per_month_base, per_month, growth, others_growth, share_base, share, excess_rub, explain}
  explain          {count_per_month [было, стало], avg_check [было, стало], count_change, avg_check_change,
                    sub [{name, per_month_base, per_month, change|null, new_since|null}]}   // new_since — «новая статья с», без процента
flagged_categories {категория: [kind…]}  // метки в «Тратах»
not_enough_data [kind…]                // не хватает истории для вида факта
```
Страница (этап 3): метка у категорий из `flagged_categories` в «Тратах»; на Обзоре «На что взглянуть» — до трёх первых `facts`; `month` старше последнего месяца `spending.json` — факты не показывать.
