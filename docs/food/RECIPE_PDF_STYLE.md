# Визуальный стиль рецептов — спецификация

Эталон: **Венгерский гуляш на свинине** (скриншот от 17.05.2026)

---

## Цветовая палитра

| Элемент | Назначение | HEX |
|---|---|---|
| `DARK_RED` | Заголовок документа, заголовки разделов, шапка таблицы (текст) | `#C0392B` |
| `TABLE_HEADER_BG` | Фон шапки таблицы | `#922B21` |
| `SECTION_BG` | Фон блока заголовка раздела | `#FEF9E7` |
| `ROW_ALT` | Чётные строки таблицы (зебра) | `#FDFAF0` |
| `ROW_WHITE` | Нечётные строки таблицы | `#FFFFFF` |
| `TEXT_MAIN` | Основной текст | `#1A1A1A` |
| `TEXT_STEP` | Подзаголовки шагов | `#1A1A1A` (жирный) |

---

## Структура страницы

- **Поля:** left 40 pt, right 40 pt, top 40 pt, bottom 40 pt
- **Выравнивание основного текста:** по ширине (JUSTIFY)
- **Выравнивание заголовка документа:** по центру
- **Межстрочный интервал:** 14 pt для основного текста

---

## Заголовок раздела — устройство блока

```
[ цветной фон SECTION_BG, padding 6pt сверху/снизу ]
[ текст DARK_RED Bold 13pt ]
[ отступ после блока 8 pt ]
```

Блок тянется на всю ширину текстовой области.

---

## Таблица ингредиентов

- Ширина: полная текстовая область (с отступом ~30pt слева и справа от края таблицы)
- Колонки: «Ингредиент» ~65% ширины, «На X порций» ~35%
- Шапка: фон `#922B21`, текст белый, Bold, выравнивание по центру
- Строки: зебра (`#FFFFFF` / `#FDFAF0`), текст по левому краю, padding 4pt
- Внешняя рамка таблицы: тонкая `#CCCCCC`
- Внутренние линии: только горизонтальные `#CCCCCC` 0.5pt

---

## Чего НЕ делать

- Никаких цветных фонов для основного текста
- Никаких рамок вокруг шагов
- Никаких иконок, декоративных разделителей
- Не использовать стандартные шрифты ReportLab (Helvetica, Times) — кириллица не отображается
- Не выделять цветом подзаголовки шагов — только Bold

---

## Шрифт

**DejaVu Sans** — обязательно. Установка:

```bash
pip install reportlab
# DejaVu Sans TTF скачать с https://dejavu-fonts.github.io/
# Или использовать системный путь если установлен
```

Регистрация в ReportLab:
```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont

pdfmetrics.registerFont(TTFont('DejaVu', '/path/to/DejaVuSans.ttf'))
pdfmetrics.registerFont(TTFont('DejaVu-Bold', '/path/to/DejaVuSans-Bold.ttf'))
```
